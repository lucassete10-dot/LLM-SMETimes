## 1. 目标和范围

针对同类型、未参与训练的新电芯，根据前期电压、电流、温度和已知工况，预测后续 SOH 曲线；同时通过验证实验寻找达到可靠效果所需的最短输入历史。

数据范围：MIT、XJTU、HUST、UConn–ISU–ILCC、Zhu2022_NCA。NASA 不在本轮主线。当前不开展实时 SOH 估计、独立 RUL 建模或 STM32 部署。

每个数据集独立报告。依化学体系、型号、容量、温度和充放电协议区分物理兼容组；数据集名称不等于电池类型。同一组样本不足时可以在物理兼容范围共享模型并输入工况，须披露各组数量和适用范围。

禁止用测试电芯未来寿命、未来拐点或完整退化形状分类。

## 2. 输入、标签与数据质量

训练电芯数量、留出电芯输入历史 N、预测区间分别记录。“循环训练次数”在本方案指新电芯可提供的前期循环数，不是训练 epoch 数。

预测输入仅限前 N 次循环内的电压、电流、温度、时间及派生特征，以及预测时已知的电池规格、工况。前期实测容量辅助方案单列，不能与纯电信号方案混报。未来容量、信号、寿命以及由这些信息计算的归一化量均不能参与预测。

未来工况未知时明确预测所假设的工况。容量标签用于训练监督和评价；不得将事后实际工况作为提前已知信息。

审计电芯身份及重复、循环编号、单位、信号范围、充放电完整性、容量计算、缺失、协议变化、停止原因和预处理泄漏。SOH 默认容量/额定容量；无可信额定容量时单独定义初始参考政策，并核验参考可用时间。不混用未标明的 SOH 定义，不直接裁掉 SOH>1。

异常排除或降权仅依据原始质量证据和预定规则。真实快衰减、恢复和困难电芯保留；数据不足与错误分别记录；保留原始记录及修改轨迹。禁止因预测误差大删电芯。

## 3. 已有缺陷与优化顺序

先重放单种子、单分量和组合预测，确认缺陷来源，再优化特征或模型。优秀案例也按相同标准核验。

| 问题 | 检查方向 | 改进目标 |
|---|---|---|
| MIT 近似匀速下降、遗漏加速 | 循环数依赖、线性分量、曲线平均化 | 区分线性与加速退化 |
| MIT 阶梯、提前转折后变平 | 逐点回归、拼接、循环映射、支持范围 | 连续且阶段合理 |
| MIT 起点偏移和加速方向反转 | 参考容量、起点预测、曲线参数 | 分别学好健康起点与后续速度 |
| XJTU b6 提前陡降后停在约0.82 | 模板寿命、末值延长、裁剪、训练支持 | 修复虚假平台及衰减提前 |
| XJTU b2_3C 持续回升 | 单分量、模板、后处理 | 合理长期趋势 |
| XJTU 转折时间和强度偏差 | 个体特征、监督与输出结构 | 分别预测何时加速及加速多少 |

图片只能证明现象，不能直接证明根因。不得通过画图平滑掩盖预测错误。保留 b1_2C_battery-1 这类优秀案例的能力，但不对着测试答案单独校正。

## 4. 特征与模型实验

相同验证电芯比较：仅循环数与工况；加入早期电信号；加入跨循环变化与阶段特征。在兼容工况内做特征打乱/交换，检查个体信息是否影响预测。

依据验证证据补充电压区间时长、曲线差分、温升、弛豫及适用的增量容量特征。所有计算截断在输入边界之前；不盲目增加特征。

模型候选：冻结现有强基线；连续退化曲线模型；连续趋势加受约束残差；样本量允许时的小型序列模型。分别学习起点、基础衰减速度、转折时间、过渡宽度及加速强度。允许无拐点和近似线性，不强迫统一形状。

## 5. 自动寻找推荐输入长度

先粗筛10、20、30、50、75、100个源循环，再在有效区间细化；必要时增加150、200次。可依数据集和工况分别推荐。

同一电芯在全部候选历史长度下的共同可用交集用于公平对照；同时报告逐长度实际覆盖，不能因增加历史而悄悄排除短寿命电芯。历史不够、容量参考尚未建立等原因单列。

两种评价分开：相同电芯、相同未来区间评价历史信息量；从各自截止点起评价实际未来预测。寿命比例只作回顾性补充，未知真实寿命不得用于决定输入长度。

验证侧先选达到曲线标准的候选，再优先选较短历史：联合通过率满足目标且距最佳不超过5个百分点；MAE比最佳增加不超过0.2 SOH pp；后期和阶段表现无明显恶化。规则在搜索前冻结。无长度达标时报告“未找到可靠输入长度”，可交付当前最佳诊断方案但不得称已达标。

这里的“较优”是已评估搜索范围内的验证选择，不宣称数学意义上的全局最优。

## 6. 划分、选择与复现

按完整电芯分组。外层分组交叉验证、内层选择模型/特征/历史长度；小组适用时留一电芯并披露不确定性。任何窗口随所属电芯划分。

归一化、特征选择和分类器只在当前训练部分拟合。随机模型至少5种子，报告逐芯和均值±标准差；确定性重复不能冒充随机不确定性。

已反复查看并用于改进的电芯标为开发数据。重新划分不消除历史使用。保留真正未接触的数据用于最终确认；如无此类数据，明确结论仅为开发验证，最终独立确认尚待补足。

每次实验保存配置、数据/代码版本、划分、种子、输入长度、模型权重、日志、耗时、逐点预测和逐芯指标，失败及中断也记录。

## 7. 预注册验收

SOH按0–1存储；pp指SOH百分点。

| 单电芯指标 | 目标 |
|---|---:|
| 全区间MAPE | ≤6% |
| 全区间MAE | ≤1 pp |
| 最后20%区间MAE | ≤1.5 pp |
| 三阶段下降量误差最大值 | ≤2 pp |
| MAE/真实衰减幅度（分母下限2 pp） | ≤25% |
| 明显加速方向反转 | 不允许 |
| 有可信拐点时的时间误差 | ≤预测跨度10% |

另报RMSE、R²、起点、单点终点和末段误差。拐点、持续回升和错误平台的检测及阈值在训练侧明确、校验、冻结。无可信拐点记不适用，覆盖不足单列，不能据此宣称完整曲线成功。

每个数据集目标：至少90%的符合预注册评测条件的留出电芯联合达标，并报告各工况、最差案例、全部覆盖和排除清单。小样本组不作强泛化结论。所有失败纳入结果；不得通过改阈值和删困难电芯达成目标。

## 8. 执行阶段

1. 审计数据、已有工程和结果，冻结身份、划分和规则。
2. 重放曲线并定位平台、回升、偏移和阶段错误。
3. 小规模验证修复、特征贡献和曲线模型。
4. 内层验证联合选择模型与输入长度。
5. 完成正式多折、多种子验证与独立评测。
6. 交付全量图表、模型和可复现结论。

输入长度搜索本身需要训练。确定较优长度后进入正式多折、多种子训练评测。一个数据集准备就绪即可推进，无须等其余数据集全部选完长度。

“训练到一个程度”的交付触发点固定为：首个完成核验的折/种子、单数据集全部计划折/种子完成、同标准下实质改进的版本完成。交付在该阶段核验后进行，不延迟到五数据集全部完成；交付范围是该阶段全部留出电芯，包含失败曲线。每轮实验仍保存结果，阶段交付不替代逐轮归档。

### 阶段A：完成一个数据集的输入长度选择

交付输入长度对照表、覆盖清单、推荐长度和选择依据、阶段说明。未达标时仍提供诊断结果，说明候选长度的局限，不阻止用户看到结果。

### 阶段B：首批可核验曲线

推荐长度下，任一数据集完成一个正式折及一个种子的预测并核验后，交付该折全部留出电芯PNG、逐点预测CSV、指标Excel、运行说明及压缩包。标明“阶段结果：1折/1种子”，不得冒充正式汇总；不只挑最好看的图。

阶段图片优先展示训练侧验证结果。独立测试图仅在该轮方案冻结后开放；看过独立测试再调参时，须承认其已转为开发用途。

### 阶段C：单数据集完成

任一数据集完成全部计划折和5种子后，交付该数据集全部留出电芯主图、种子结果、Excel、配置/模型清单、推荐长度、通过率和失败分析。每颗电芯主图展示种子均值与波动；种子波动不标为预测置信区间。

### 阶段D：实质改进与最终交付

后续候选在相同训练侧验证上有实质改进、覆盖发生变化或发现影响结论的问题时，交付带版本号的更新及前后对照。每次实验都保存；不必每个epoch发送文件。最终打包五数据集全量结果。

每个阶段包包含时间/运行ID、完成折和种子、已评测/计划电芯数、输入长度、验证或独立测试身份、未完成项、核验状态与文件索引。发送阶段包不视为goal完成，执行授权生效后继续后续计划。

### 交付时机与输入长度结论的补充约定

- 完整方案随 goal 保留：goal 入口明确引用本文件，并保留关键范围、禁止泄漏、长度选择及阶段交付要求；本文件是最新执行依据，旧快照只用于追溯。
- 输入长度搜索本身需要小规模训练，不能理解为先凭经验定好次数再训练。各数据集报告已评估的候选长度、覆盖范围、验证结果、推荐长度及其适用工况。
- 找到推荐长度后冻结该轮模型选择规则，再开展正式训练。首个折/种子完成并核验后，在下一次进度回复中提供可打开的图片和文件链接，不仅描述数字或承诺稍后交付。
- 未找到达标长度时，仍交付阶段A对照结果及当前最佳候选的诊断曲线，并明确“尚无可靠推荐长度”；后续改进继续在训练侧验证，不能使用独立测试答案挑长度。
- 图片按数据集、输入源循环数及运行版本整理。首批只代表已完成部分；单数据集完成时补齐全部留出电芯图及五种子结果。图数随实际覆盖确定，同时列出计划数、已交付数与缺失原因。
- 阶段交付不是性能达标声明。不得把“已有文件”“低MAPE”或“完成一折”当作整个 goal 完成。

## 11. 完成与暂停条件

性能goal完成须同时满足：五数据集审计及规范评测完成；分别达到预注册联合通过率；推荐长度经验证侧选择和独立确认；已知缺陷有诊断和验证；全量图、Excel、权重、日志和复现说明齐全。
