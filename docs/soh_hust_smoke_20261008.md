# HUST数据接入冒烟与输入历史对照预注册

只在HUST物理兼容组训练，不与MIT等混合。77颗电芯按完整电芯、seed20261008固定5组；第1组保留外层，第2组作内层验证，其余作训练。数据接入审计读取全体源数据不等于模型加载外层；训练进程不加载外层电芯NPZ，不用其标签选取候选。

单折单种子先比较30、50、100次输入；只含这些循环固定首300s放电V/I及已知协议、额定温度，无容量输入，温度为已知30摄氏度而非实测。未来标签容量/1.1Ah，共同未来区间第100次之后。保留初始SOH>1。

候选：逐点ExtraTrees80树leaf1、leaf4；非负衰减速度积分80树window25 leaf3，共9次拟合。积分共用leaf1起点预测，原始容量不平滑改写。各候选同电芯、等电芯权重。指标与continuous_length开发筛查一致，拐点尚未正式核验，不宣称最终通过或最优长度。

HUST包含不同放电协议，因此本实验为已知工况条件化的留出电芯开发验证，不宣称同协议未见电芯或独立跨工况泛化。部分源协议元数据与记录电流可能不一致，须进一步核验。信号不足按预设规则处理并报告，禁止按预测误差排除。

保存划分、索引/源码哈希、模型权重、每条曲线及指标、重放/未来污染/物理类型拒绝核验；失败也归档。后续多折多种子和可信拐点评测仍需执行。
