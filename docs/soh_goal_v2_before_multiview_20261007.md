# Goal v2：同类型未见电芯的未来SOH预测与完整评测交付

修订日期：2026-10-07。依据用户“现在修改一下goal”的明确指令，
本文件替代2026-10-06方案作为后续工作规范。旧方案、实验、权重、
源码快照及原验收结果保留，不重写历史结果。

用户已删除旧系统Goal，并明确授权依据本方案创建新Goal。
新目标从现有模型、实验和交付状态继续，先核验已有结果与输入合同，
再依下列固定预算执行必要实验。旧目标没有被虚报为完成。

## 1. 功能与范围

针对MIT、XJTU、NASA、Zhu2022 NCA已有数据，按已有物理证据隔离
不兼容电池家族，从同类型训练电芯学习，在未参与训练的新电芯上，
输入前100源循环内的电压、电流、可用温度和已知规格/工况，输出
未来指定循环位置的SOH曲线。预测位置由请求提供，不将真实终止
寿命、未来容量、未来测量或完整真实曲线参数作为输入或分组依据。

同家族内部可使用共享或工况模型；训练支持不足时回退家族模型。
NASA物理类型证据不足继续标注，结果属于四芯公开队列开发评测；
不宣称可自动识别任意电池类型或具备已证明的部署泛化能力。
不新增实时SOH估计、RUL、新数据集或STM32部署任务。

## 2. 两级验收

### A级：本次Goal的完成标准（全部满足）

1. 四个队列分别评测，均满足电芯等权的全未来平均MAPE≤6%、
   后半段平均MAPE≤6%、逐芯RMSE均值≤0.04（SOH采用0–1）。
   不能把四队列合并平均后宣布达标。后半段与未来点范围沿用已有
   固定评测实现；在最终报告中明确其定义，冻结后不改变。
2. 使用固定整芯外层划分覆盖全部正常评测电芯。内层用于训练方案、
   超参和模型选择；任何电芯不能同时属于该次拟合训练与评测角色。
   随机模型至少5种子；先逐种子电芯等权汇总，再报告均值±标准差。
   确定性方法完整重复结果可复现即可，不伪造独立种子或置信区间。
3. 查询仅使用约定早期输入；标准化、缺失填补、筛特征、聚类、路由
   全在对应训练侧拟合。所有复用候选需核实输入合同，旧Ah/Wh等
   Q相关输入候选可保留比较，但不能未经核验冒充本Goal合规主模型。
4. 每芯输出真实/预测曲线和MAE、RMSE、MAPE、R²、后半误差、起点、
   末点、drop误差；列出全部未达到B级的正常电芯。必须显示较差结果。
   R²不可定义时如实标注。未来点数<10或跨度<100单独标注，不能
   以短覆盖误差声称长期曲线预测成功。
5. 所有正常电芯保留评测。仅依预先固定的数据完整性/物理合理性规则
   排除明确损坏、无效、重复等记录，并保存原因与数量。不能因为
   MAPE高、容量回升、寿命特殊或模型预测不出而删除。
6. 冻结最终模型方案及完整评测清单；原始预测、指标、模型来源和
   数据/源码SHA可追溯，独立重算一致。保存配置、种子、划分、
   权重、耗时、日志；生成下面规定的最终表格、Excel、曲线和结论。
   逐芯图全部检查，保证图中真值/预测对应同一电芯和循环坐标。

A级是平均误差与工程评测完整性的验收，不等价于每颗电芯MAPE≤6%。
报告必须同时列出每队列逐芯MAPE≤6%的数量、比例及最差电芯指标。
已有记录表明平均指标可能接近A级，但必须完成输入合同、复现及
交付检查后才可正式认定；本次修改不直接宣布Goal完成。

### B级：曲线贴合增强指标（全部报告，暂不阻塞A级完成）

- 平均末点误差≤5个SOH百分点，平均drop误差≤4个百分点。
- ≥90%电芯同时满足全MAPE≤6%、后半MAPE≤8%、末点≤8pp、drop≤5pp；
  NASA增强目标仍为4/4。
- 真实下降≥5pp，但预测不足真实下降30%或反向的严重失配率≤10%。
- 对照冻结旧模型，末点及drop误差P90下降≥20%；原P90≤3pp则保持
  ≤3pp；全未来MAPE回退不超过0.5个百分点。

drop误差=100×abs((p_first-p_last)-(y_first-y_last))。
上述B级指标逐队列列出数值、是否达到和差距，保持原公式和旧基线。
A级完成而B级未完成时结论写“基础未来SOH预测完成，曲线增强未全部
达到”，不得写“所有电芯均高度贴合”。理想图片不是全芯硬性标准。

## 3. 收敛执行方式

1. 先整理并冻结现有各队列内层选模方案，核实输入、划分及来源。
   从已锁定的内层选择恢复方案，不能根据已观察外层成绩挑最好模型。
   汇总现有完整开发CV原始预测，优先补交付与审计缺口。
2. 公开外层已多次观察，所有当前结果继续称“开发交叉验证”，
   不称独立盲测。换种子/重分同一批已见数据不会变成真正新盲测。
3. 已满足A级数值且输入合规的队列，优先冻结、核验和交付。B级未过
   记录为增强限制，不自动触发无限新实验。
4. 仅对A级数值/输入合同尚未满足的队列开展新实验。每队列本轮最多
   2个有证据依据的新配置，训练前写明假设、参数与选择规则；使用
   相同内层整芯折与相近训练预算比较，然后锁定至多1个候选进入
   一次完整外层开发CV。禁止用外层逐芯真值选参数/拼接/修正。
5. 新实验沿用现有内层综合score选模，精确平分保留已有模型。
   历史实验原“末点/drop不得退步”等扩展门及不采用结论不回写。
   如确需重新评估旧失败候选，必须记为本轮新配置并占用预算，
   不能因新版门变宽就把历史失败结果自动升级成采用。
6. 不再在同一小批验证电芯上连续尝试校准系数、斜率窗口或集成权重。
   本轮固定预算耗尽仍未达A级时，保存负结果并提交具体剩余缺口和
   下一步证据需求，不自动追加同类参数搜索或降低阈值。

## 4. 交付物与完成判断

- 最终模型/选模与数据来源清单，说明每个队列的输入合同及物理类型
  证据限制；可复现运行说明与配置。
- 四队列A级验收总表、全部B级增强指标表、逐芯指标和失败原因表。
- 完整Excel汇总（总览、逐芯、各随机种子、曲线增强、异常规则、
  模型/实验来源）；完整逐点预测通过Excel附表或明确链接的NPZ交付。
- 按最终清单每颗评测电芯一张真值/预测曲线，并有4张队列总览。
  当前记录为248颗，因此预计248张逐芯图+4张总览；最终数量由
  固定清单核对，不通过删掉失败芯凑数。图片数量不是唯一完成标准。
- 简短结论：A级是否完成、B级还差什么、哪些结果是短跨度/小样本/
  已观察开发CV、可支持和不可支持的实际使用结论。

只有四队列A级全部通过并完成全部交付核验，才允许标记本Goal完成。
届时B级可以仍有未满足项，但必须准确报告；不会将旧严格Goal的
历史结果改写为已达标。本文件是用户授权的目标变更，非实验中途
为某个模型调整计分。
