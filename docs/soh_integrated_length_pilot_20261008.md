# 积分衰减速度与输入历史：开发验证预注册

范围：MIT、XJTU、Zhu2022_NCA现有冻结fold1的训练与内层验证电芯；不加载外层测试。仅诊断实验，不认定最终长度或最终通过。

标签统一容量/额定容量；输入采用continuous_length的因果V/I/T特征。公平对照用全部长度共同可用电芯，未来区间固定源循环100之后。输入默认30、50、100循环；训练种子20261008。所有结果归档，不按误差删电芯。

候选固定为point/VIT/leaf1（80树）与integrated_rate/VIT的window10 leaf1、window25 leaf1、window25 leaf3（各80树）。各候选共享同一训练电芯、同一起点模型。起点位于训练标签最早未来循环，由训练点模型预测，不读取验证真实容量。局部速度标签仅由训练电芯未来监督生成，负衰减速度截为0，代表长期不可逆趋势的模型假设，原始真实曲线不修改。等电芯权重。

预测速度按1循环固定网格中点积分，无下限裁剪、末值续接或预测寿命映射。输出长期趋势不回升，但不强制始终加速。零速度仍可能形成平台，必须按原始结果报告。模型输出不会因为绘图平滑而改变。

评价使用与continuous_length相同的MAPE、MAE、后20%MAE、阶段下降量误差、加速反向指标及当前screen_pass；可信拐点门槛尚未独立验证，不得称联合正式达标。模型是否采用依赖内层验证完整曲线误差，不以终点接近或图片好看选取。

核验：保存再加载重放、未来信号/标签污染不变性、物理类型拒绝、训练侧预处理重建、密集网格非回升。保存配置/代码哈希/权重/逐点预测/全部逐芯指标及失败状态。
