## 方法和规则核对

真实计算图为：可见历史数字投影/文本卡 → 固定预训练Llama3.2-1B → SMETimes融合专家 → LLM历史token读出 → 起点、速率积分和有限局部修正。所有输出分支依赖LLM历史表示；没有独立树模型、答案教师、按待测电芯自由拟合或真实SOH平移。主干文件和训练源码快照哈希由独立66模型审计核验。实际数字投影梯度存在，B的LoRA梯度存在。

S_val按逐电芯MAE/2、TailMAE/3、起点/1、终点/3、阶段/3的可用项平均，加最差ceil(20%)电芯均值的0.25倍。缺失指标由真实采样在预测前冻结，同划分候选处理一致。66实际检查点为最早的最小S_val；缺失和非有限预测不能获低分。后期MAPE由最后20%真实源循环跨度单独计算。

实际快速预算120（min40、eval10、patience4），正式/确认240（min60、eval10、patience6）；有效改善0.5%。每次实际训练历史已核对提前停止时刻和预算上限。每个A/B配置逐项与R0核对，仅登记单因素变化。full_train_targets数量由各折TRAIN原始观测数解析，没有据TEST寿命决定。

A/B接受要求≥5%验证分数改善、MAPE通过数不下降、最差MAE≤1.1倍。10项均不合格，因此按停止规则采用R0，15次确认复用于正式覆盖。C/D的条件为VAL/TRAIN均值MAE≥2且至少20%密集TRAIN满足登记噪声条件，五数据集均未触发。最多300轮扩展是可选欠训练诊断，本次未启用，未用更高预算替代锁定240轮对照。

选择锁由VAL证据写入后才访问TEST；formal模型与锁哈希一致，非formal候选没有TEST预测。已查看TEST属于开发留出。TRAIN/VAL原选点预测与实际重载模型作比较；第一次TEST没有原选点缓存，其预测由重载模型生成并完成独立查询、顺序和污染检查。没有把不存在的TEST重载差值填成零。

HUST77和UConn64全源参与与16/11颗固定TEST范围分开；UConn稀疏RPT仅评价真实观测点，缺失阶段仍为unavailable，没有制造稠密逐循环证据。385电芯输入审计保留各数据集实际缺失通道、源循环和单位限制。
