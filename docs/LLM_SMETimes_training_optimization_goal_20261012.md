# LLM + SMETimes 电池预测训练与算法优化 Goal

版本：2026-10-12；状态：已设定并开始执行。

## 目标与主要验收

以真实预训练 LLM + SMETimes 完成 MIT、XJTU、HUST、UConn_ISU_ILCC、Zhu2022_NCA 的全名单训练与预测评估，并开展有明确对照、可复现的算法优化。按最新指示，先让所有数据集产出最小 MVP，再补齐各数据集折次、种子和算法优化。

主要目标为 MAPE ≤3%。同时保留实用目标：全程 MAE ≤2 个 SOH 百分点、后期 MAE ≤3、起点误差 ≤2、终点和阶段下降量误差 ≤3。单独报告达到 MAPE 目标的比例，以及同时达到全部实用目标的比例；不把两种比例混称。1 个百分点等于 SOH 0.01。

重点看整体趋势、前后期下降量和后期加速是否跟上，不要求模型复现孤立容量尖峰。拐点区间、相对衰减误差和原严格指标作为诊断参考，不再用于限制启动完整训练。预测图和误差仍基于原始容量标签，不通过平滑真值、删失败电芯或移动曲线来达标。

这些阈值是项目目标，不是行业统一标准。3% 是用户最新明确指定的目标；历史成绩需公开标明重新统计口径，不能改写成旧目标已经通过。

## 方法与数据约束

所有预测分支保持真实 `models/llm/llama-3.2-1b-instruct` 预训练主干、数字/文本历史融合、SMETimes 专家和曲线查询解码。允许数字路径 LoRA 和同一 LLM 历史表示条件下的解码优化。不得换成树模型、独立非 LLM 预测器、目标答案教师或按待预测电芯拟合系数。

仅输入预算内真实可见的 V/I/T/time 与事先已知工况。不得输入容量/SOH、未来信号、真实终点、未来工况或以真实寿命归一化的时间。容量仅用于监督、审计和标签参考。TRAIN 拟合缩放器与权重；VAL 选检查点与算法；TEST 在候选确定后评估，不参与算法排名。

各物理电芯划分和已知续接排除规则保持冻结，各数据集单独训练。缺失的测量保持缺失，UConn 的稀疏 RPT 不伪装成逐循环测量。已查看的数据仍称开发/留出评估，不宣称独立盲测。物理型号和工况映射尚未确认的限制随结果交付。

本轮输入预算固定前 100 个实际源循环。未擅自扩大到 200 循环或改变已有标签定义；预算扩展需单独重提取并建立对照。

### G2：每个数据集的有限算法优化

所有数据集 MVP 完成后，在该数据集完整基线跑完之后执行；先在首折 seed 20260930 与同折同种子基线对照，每次只改一项：

| 候选 | 唯一改变 | 待检验假设 |
|---|---|---|
| A | 局部修正最大幅度从 1 pp 降到 0.5 pp | 减少局部噪声过拟合 |
| B | 向量节点读出改为共享查询读出 | 减少节点记忆并改善时间形状泛化 |
| C | 数字路径启用 rank=4 LoRA | 改善真实 LLM 对数值历史的表示 |
| D | 逐点/尾段 Huber 转折从 0.1 pp 改为 0.5 pp | 减少拟合微小噪声的压力 |

选择规则预先固定：验证分数为等电芯权重的 `MAE + Tail MAE + 0.5 × Stage error`。候选需相对基线改善至少 10%，最差验证电芯 MAE 不恶化超过 10%，达到 MAPE≤3%的验证电芯数量不减少。失败候选照实留档。

- [ ] 每个数据集完成四项对照；筛选阶段只做 TRAIN/VAL 审计，不请求候选 TEST 预测。
- [ ] 合格候选只选一个，用 seed 20260931、20260932 复核；三种子中至少两个改善，平均验证分数改善至少 10%，最差电芯和 MAPE 通过数仍满足上述保护条件。
- [ ] 验证证据锁定后，才进行胜出候选的 TEST 评估。
- [ ] 有确认收益时，以胜出配置完成该数据集原全部折次和三种子；复用三个已完成的拟合，不重复训练。
- [ ] 没有候选通过时保留基线，交付负结果与问题列表，继续下一数据集；不无限搜索，也不把 TEST 当验证集。

执行完成必须包括全部计划的数据训练、有限算法对照及复核、重放核验和结果交付，不能仅因目标文件写完或进程启动就标完成。数值目标是否达到另行统计；未达到 MAPE≤3% 的电芯保留具体问题和改进建议，不能用放宽其他阈值、均值或删电芯遮盖。算法未改善时必须报告负结果，不能宣称优化成功。
