# 修订目标：真实电池类型内的未来 SOH 预测

用户于 2026-09-30 要求将 Claude 的严谨评测方案与现有功能目标结合，并启动新 goal。本目标取代原功能开发目标；历史数据、代码、模型和失败结果全部保留。

## 目标与边界

见过一种实际规格的电池后，根据另一颗同类型电芯已观察到的电压、电流、温度与已知使用条件，预测未来 SOH 曲线。主目标为逐电芯宏平均 MAPE 约 6%，不是承诺所有电池都达到 6%。实时 SOH 检测、独立 RUL 暂缓。

物理类型与工况分开：化学体系、厂家/型号、形态、额定容量、额定电压和允许电压范围构成物理规格；温度、倍率、充电策略、实验深放电截止电压属于工况。批次是来源/工况追踪信息，不是化学体系。400/800 次循环只能是模型依据前缀预测的寿命倾向，不能用测试电池真实终寿命分组。

MIT、XJTU 与 NASA 不能仅凭 SOH 曲线相似归为同类。NASA 缺失的化学体系/型号保持未知、独立未核验组；XJTU 型号编号也未在作者发布页给出。外部匿名电池缺关键参数时返回需要补充规格，不强制分类。去类型输入的消融仍必须保留物理兼容门禁。

## 执行顺序

1. 继承已修复的数据，核查真实规格、标签/归一化参考、重复与异常、整电芯划分、训练侧预处理和类型识别；产出 `audit_report.md`。发现泄漏撤销相应结论并重跑。
2. 注册物理类型并冻结五折整电芯划分、内层验证和五个训练种子。NASA 四电芯留一仅作补充，不假装样本量充分。
3. 单折单种子冒烟后，在相同输入/划分/预算下比较强基线、专用小序列模型、真正冻结预训练小 LLM 的 SMETimes 统计提示+确定性 SOH 输出头。
4. 做随机初始化、无 LLM、无提示、专家数量和去类型条件输入消融。原模型的门控 L1 正则乘零且本身为常量，必须在新实验中正确处理；不能把密集专家宣称为稀疏省算力。
5. 主实验完成后做合理跨工况/至少两方向跨数据集补充，未知/不同物理类型保持不同；零样本与目标侧校准分开，不能根据测试结果反复选方法。
6. 逐电芯输出曲线、RMSE/MAE/MAPE/R²、短程/末段误差与预测覆盖；种子波动、折差异、电芯差异分开。如 LLM、预训练、多专家未赢，直接报告未赢。

主起点是固定源循环 20/50/100，评 +10/+50/+100 和全可观察未来；真实总寿命 20/40/60% 仅回顾性补充。主输入没有容量/SOH/EOL，也没有未来信号。历史容量增强必须独立报告。参考容量只决定评价标签，不能作为输入；其建立时点及早期可评估性要明确。

每个实验独立时间戳目录立即保存配置、数据/源码指纹、划分、种子、日志、权重、预测、指标、图、资源及失败信息，不覆盖以前任何训练。全部公共数据已查看，只能称开发验证，后续用户提供的新数据才可另作盲测。

## 验收交付

物理规格/质量注册表、冻结配置与划分、`audit_report.md`、`results/summary.csv`、主对比/消融/跨域/早期表、逐电芯曲线、可用循环数误差图、可复现训练与原始前缀推理代码/权重、一页 `conclusions.md`。五折五种子与真正 LLM 的贡献尚未完成，原树模型数字不能替代它们。
