# XJTU固定模型路由对照（训练侧）

先验诊断：冻结分段特征内层验证显示，起点误差较小，但下降幅度常被
低估。局部路由组误差较高是描述性关联，不能据此认定路由造成误差。

固定XJTU_fold1、seed20261005及已锁定candidate6（VIT/segments）。
不重新挑选特征、叶大小、树数、种子或电芯。只比较局部权重0、0.5、1；
权重1为原硬路由对照。无局部支持时三者均回退同家族共享模型。
所有权重统一应用，禁止按验证电芯单独选择。仅加载训练/验证电芯，
不读取外层预测。保存完整预测、配置、模型依赖SHA和日志。

最低验证score优先、并列保留权重1。只有score降低、MAPE增加≤0.1
百分点、endpoint与drop均不增加，才能考虑5折5种子扩展。
独立逐树重放、数值核算和输入污染检查后才确认小规模结论。
此对照不新增树训练，已有内层模型经独立重训核验，不算新的训练成果。
