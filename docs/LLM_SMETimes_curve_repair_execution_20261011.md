## 不能靠继续训练解决的限制

`P0_20261011T062718_681671Z/TRAIN_b1c0_shape_lower_bound.json` 给出了可重放的线性规划下界：任意“非负衰减积分 + 单一饱和恢复”曲线，其累计向上变化不超过恢复幅度。允许任意离散曲线但保留这个总变化预算，所得全局最小 MAE 是原模型类的下界。

| 总向上变化预算 | TRAIN b1c0 的最小 MAE 下界 |
|---|---:|
| 0 pp | 0.23629 pp |
| 0.5 pp（当前约束） | 0.23164 pp |
| 2 pp | 0.22176 pp |

三者均超过 P1 的 0.2 pp 门槛；提高优化器效率或无限加密非负速率节点无法改变这个结论。下界无额外阶段、起点或拐点约束，因此不是其他门槛造成的失败。

同时，直接拟合 TRAIN 答案的固定节点表达能力诊断（非预测、非教师）显示：14 节点只能使 9/12 满足 P1，65/129 节点可使 11/12 满足，剩下的是含大量尖峰的 b1c0。MSE 与 L1 均检查过。

对“有界局部正负残差”做自由参数可行性诊断，50/25/10 循环间隔仍不能达到 b1c0 的 0.2 pp；5 循环间隔、1 pp 幅度可到约 0.19675 pp。**这是已知 TRAIN 答案下的表达能力结果，不是仅凭前 100 循环能预测未来尖峰的证据。不能为了通过 P1 把未来尖峰当作可预测的老化规律。**

## 标签证据与尚未解决的事项

b1c0 的极低点和相邻循环 Qd/summary 一致，但记录的 I/time 积分变化明显小于 Qd 波动。例：循环 769/770 的 Qd 为 1.04485/1.00835 Ah，记录负电流的积分单位换算正确后约为 1.05149/1.05145 Ah。作者固定 1.1 名义电流换算后的原始 MAT SHA256、积分定义和相邻循环证据见 `P0_20261011T064504_297599Z/TRAIN_b1c0_spike_trace_audit.json`。旧未换算积分保留在历史记录，但不能作为安培小时物理值使用。

这提示需要进一步核查作者处理流程、设备记录与积分假设；目前不能直接断言哪个字段正确。没有改写 Qd、参考容量、标签或现有筛选规则，也没有用未来容量作为输入。此前“主要是容量恢复幅度不够”的推测已撤回，现有证据指向局部尖峰与曲线族约束冲突。

## 单位与训练支持范围的新增问题

[作者处理代码](https://github.com/chueh-ermon/BMS-autoanalysis/blob/master/cell_analysis.m)以 `I = Current / 1.1` 保存电流，时间以分钟保存。本地旧 MIT 特征名和文本卡片却将这个电流字段标为 A；相应短时积分也被误标为 Ah/Wh。已新增 `battery_smetimes/mit_units.py`，按固定公开的 1.1 A/C 比例转换电流和电流派生列；不使用电芯测量容量、SOH 或未来寿命作单位换算。

修正数据使用 `physical_amperes_v2` 明确版本。`load_frozen` 在校验旧文件哈希后创建转换副本，旧缓存和旧权重可继续按 legacy 合同重放；标签、参考容量、划分与其他通道不变。新 P0 的 b2c1 重提取一致误差仍为 0，标签偏差仍约 `4.5e-8 SOH`。作者原始代码已下载作只读证据并记录 SHA256，未执行外部代码。

这不是直线塌缩的充分解释：训练标准化能抵消固定尺度的主要数值影响，主要变化在物理语义与 LLM 文本输入。单位修正训练没有全面改善指标，仍需与结构修复区分。

`P0_20261011T064504_297599Z/TRAIN_and_viewed_failures_support_audit.json` 显示：TRAIN 的 83 颗电芯第 100 循环 SOH 为 `0.97228–1.01111`，末次记录源循环范围 `326–2237`；图三 b2c1 对应 `0.90568` 与 `170`，两个维度均在训练支持范围外。其末次可见电压相关特征也有较大 TRAIN MAD 偏离。这支持状态外推困难的解释，但不能把局部字段偏离当作已证明的因果原因；这些已知失败电芯没有被用于选模型或重划分。
