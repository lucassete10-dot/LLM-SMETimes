# NCA 固定起点＋归一化下降率小试（Stage80，训练前固定）

Stage79只证明TRAIN自身曲线拟合参数对记录窗口敏感，不证明保留模型
误差的原因。故本轮不继续学习整条曲线拟合系数，比较逐时距监督。

保持NCA_fold1原39训练、5验证、11外层隔离，种子20261005。
冻结Stage75 candidate_1的训练侧起点头及其imputer；不复用下降量头。
两个新HGB率头，tail_weight=1或3，其他参数与Stage75相同。
目标r(c)=(y101-y(c))/(1+(c-101)/100)。推理
p(c)=预测起点-(1+(c-101)/100)*预测r(c)+预测r(101)。
这样起点严格不变，较远时距的下降通过显式时间尺度恢复。
不是旧fade_rate：这里采用实际TRAIN y101监督、冻结信号起点头、
HGB率头和自身起点校正；旧方案采用固定或曲线拟合anchor及ET。

仅早期VI与已知工况；无查询容量/未来标签/真实寿命输入。
沿用原采样、整芯等权及selection_score。相比锁定旧inner winner，
只有score降低、MAPE不增超过0.1个百分点、endpoint/drop均不增加，
才允许扩展。不能因一颗漂亮曲线扩展；不改任何全Goal验收门。
保存3方案×44芯=132曲线、全部指标/模型/配置/源码数据SHA/日志。
随后另写采样、率目标、重拟合、公式及污染/家族隔离核验。
