# 新目标输入审计：第一轮结果

本轮不训练、不改变模型，不按外层结果挑选模型。

已逐个读取95个正式外层模型包（MIT25、XJTU25、NASA20、NCA25），
检查顶层训练电芯恰为对应train+validation，所有嵌套训练电芯都属于
该集合，且与外层test不重合。覆盖248颗不同外层评测电芯、5次运行。
这不等于证明所有预处理、路由和内层选择均无泄漏；仍需来源核验。

这里的“待核验”不是“已证明泄漏”或“必须重新训练”。
新版目标要求旧Ah/Wh相关输入经过核验，并未禁止用早期电流/电压
计算合法的统计特征。源码检查显示：

- MIT `prepare_mit.feature_vector` 的Ah/Wh来自前300秒电流与电压积分，
  不是完整放电QDischarge标签。
- XJTU `prepare_xjtu.stage_features` 的early_throughput_ah来自前120秒
  电流采样积分，不读取完整放电容量标签。
- NASA `adapt_nasa_mat_v2.prefix_features` 的Ah/Wh来自前1000秒电流和
  电压积分，函数明确不读取Capacity字段。

因此下一步应核验实际准备数据、原始提取器与历史快照的对应关系，
以及查询只取前100源循环、未来标签变动不影响预测的独立证据。
不能仅凭特征单位Ah就删除合法输入，否则会无端改变任务并损害模型。

四队列历史预测的A级三个数值门均通过；这些数值来自已有独立逐点
重算报告，而不是本脚本重新预测。正式采用仍需要输入/来源及交付核验。
本轮不宣称Goal完成，也未消耗每队列两个新配置的训练预算。
