# NASA特征组消融：训练前固定预算

依据248芯覆盖审计，先对NASA小样本起点/速度进行组别消融，之后再决定
其他队列实验。保留所有旧结果/权重/源码，不用外层B0006等失败选择参数。

12个新增确定性候选：V/VI/VIT三组×absolute/delta两模式×Ridge alpha10/100。
V=0..10、33..35；VI再加11..21、36..37；VIT再加22..32、38..41。
42/43(Ah/Wh)不输入，新候选也不混入有积分输入的旧Ridge曲线。
delta为每个通道减本芯前5观测中位数，已知cutoff始终保留。
只用训练芯前100循环SOH作为校准监督；预测新芯只看V/I/T。
最后30源循环的推断健康值以Huber直线外推，系数使用实际源循环位置。
本轮检查组别作用，不声称该线性趋势能够解决所有非线性退化。

对照为Stage49每父折已锁定选择的训练侧预测（有旧积分特征，单独声明）。
每父折原train+validation三芯轮流留一，外层不加载；每次两个训练芯。
13候选(含对照)共468曲线，144新Ridge组件拟合。保存早期推断健康轨迹。
评分沿用原Goal。扩展条件：至少3/4父折胜出、至少两折选择新特征候选，
平均末点/drop不退步，平均MAPE≤对照+0.1；未通过不做正式外层训练。
起点误差只诊断不改选择评分；确定性单种子不当作多随机种子证据。
