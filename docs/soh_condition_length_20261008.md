# XJTU已知协议分组与输入长度对照

开发实验，不加载冻结外层测试，仅原有fold1训练/内层验证电芯。按完整电芯、原始已知充放电协议分组，不根据寿命、拐点或测试答案分类。额定容量2Ah SOH，输入50/100循环可见V/I/T，共同未来区间第100循环之后。所有长度使用同一可用电芯交集。

训练组至少3颗电芯时提供独立组模型；不足时物理兼容的全体XJTU模型回退，明确记录路由及样本数量。3颗是本次预定诊断下限，不代表足够可靠；需多折/多种子验证。比较全局逐点、局部逐点、局部衰减速度积分，ExtraTrees80树leaf1，积分window25。全局/局部锚点均只由对应训练电芯拟合。允许近似线性，无绘图或终值裁剪。

先1种子冒烟，再可按同配置5种子重复，搜索范围不据外层答案修改。所有候选同验证电芯、保存权重配置、源码哈希、逐点和全部逐芯结果；运行核验未来污染不变性、不同物理类型拒绝及权重重放。指标同continuous_length诊断筛查，拐点门槛未最终核验，不能称正式联合通过。
