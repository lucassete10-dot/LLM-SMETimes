## 要达到的曲线行为

接近真实起点；缓慢衰减段斜率合理；有后期加速的电芯能跟上加速；尾段不长期偏离。保持原始容量标签，不要求拟合孤立尖峰。MAPE≤3%为主要目标，尾段、起点、终点和阶段下降量继续分开报告，防止低全程 MAPE 掩盖末期失配。

“每颗都接近”是优化方向，不是已经达到或可以保证的结果。前 100 循环信息不足、未来工况变化或跨电芯差异可能限制可预测性；失败电芯仍须完整交付。

## 当前直接执行的四项比较

沿用已登记流程，每项只改一个因素，先用 TRAIN/VAL 比较。

| 改动 | 针对的问题 | 判断依据 |
|---|---|---|
| 局部修正幅度 1 pp → 0.5 pp | 局部节点记忆训练噪声 | 验证误差下降且最差电芯不恶化 |
| 向量节点读出 → 共享查询读出 | 不同时间节点各自记忆、形状推广弱 | 阶段/尾段验证误差改善 |
| 数字路径 rank=4 LoRA | 冻结 LLM 对数值历史的适配不足 | 数字路径真实梯度及验证收益 |
| Huber 转折 0.1 pp → 0.5 pp | 训练压力集中于微小噪声 | 整体和尾段验证误差同时核对 |

四个假设尚未由实际对照证实，不能提前宣称有效。候选按预登记的等电芯验证分数、最差电芯保护及 MAPE≤3%通过数筛选；胜者用另外两个种子复核后，锁定配置再评估 TEST。保持所有五个数据集训练及原全部折次，不为挑选漂亮曲线缩小名单。

## 若四项比较仍不足：下一轮的登记条件

先交付本轮结果，再依据 TRAIN/VAL 的失败类型登记有限的新比较，不随意叠加改动或按 TEST 电芯调参数。

1. 起点偏差：核对容量参考单位、源循环对齐及前缀输入；仅在存在证据时改输入归一化或学习起点分支，禁止利用真实未来 SOH 平移预测。
2. TRAIN 与 VAL 同时漏掉后期加速：检查退化速率节点的饱和、时间范围及梯度，再比较更灵活的 LLM 条件速率解码或阶段损失。新损失和检查点选择规则须在运行前登记。
3. TRAIN 很好而 VAL 差：优先比较共享解码、正则化与早期曲线表示；前缀内多尺度 V/I/T 特征必须保持因果，并通过既有标签删除与未来污染检查。
4. 全程指标好但尾段差：训练分段等电芯权重及尾段/下降量权重做单因素比较，避免长寿命平缓段主导梯度。不能把加入抖动或更强弯曲当作准确率提升。

增加输入循环数属于独立的信息预算实验，当前不扩大前 100 循环预算。扩大预算、修改标签或未来条件都不能与当前结果混称同一任务。

检查点选择的新增证据：MIT fold3 seed20260932 运行至第 280 轮时，第 50 轮验证 MAE 1.9982 pp、尾段 MAE 3.6485 pp，旧严格联合通过数为 0；第 280 轮通过数为 6，却有 MAE 4.0989 pp、尾段 MAE 9.1344 pp。源码 `scripts/train_llm_soh_mvp.py` 的 `evaluate` 先按严格通过比例、再按平均误差选择检查点，因此会发生这种取舍。它与当前用户重视整体和尾段贴合的方向存在差距。保留当前基线及四项注册对照规则；后续应单独登记“按实用验证误差选择检查点”的比较，并用 TRAIN/VAL 证据复核，不能根据 TEST 重新挑选历史权重。详见主队列优化目录下 `ongoing_validation_checkpoint_tradeoff_20261012.json`。
