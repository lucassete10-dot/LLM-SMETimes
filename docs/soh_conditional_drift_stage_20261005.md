# 第七阶段：早期信号条件化残差（冒烟预登记）

第六阶段共享时间漂移不稳定。本阶段检验芯间信号差异是否能解释漂移，
不重复更大的全局时间头、不按外层失败芯单独校正。
复用四家族首折seed20261005已独立核验的基模型和整芯OOF残差；
来源experiments/crossfit_drift/20261005T042311_372306Z冻结，不再选基础模型。
每家族只加载冻结train/validation，不加载外层芯。

在固定请求cycle101提取现有前100信号输入，去掉所有目标信息，仅作为
固定维度前缀表示；NCA的时间乘积在此固定坐标下仅是冗余线性变换。
训练电芯每芯一行拟合中位数、StandardScaler及PCA（非按未来标签行拟合PCA）。
PCA维度为min(预登记2或4,训练芯数-1,特征数)，不whiten。
残差回归输入为[h..h^d, z, z*h..z*h^d]，h=(未来源循环-100)/100。
训练残差来自OOF模型；不使用真实寿命比例，不用测试容量/SOH/未来信号。
残差Ridge alpha100，回归输入Scaler只拟合训练残差行，等芯尾部权重3。

固定四设置：不校正；PCA2/一次h；PCA2/二次h；PCA4/二次h。
四家族共12新残差拟合、16验证设置；不重新拟合基础树。
保存配置/源SHA/基础模型SHA/OOF数组SHA/头/完整验证曲线/日志/全部误差。
家族硬隔离及未来污染不变量；独立核验PCA仅训练芯拟合、OOF坐标残差/
Ridge闭式解/完整预测与固定评分。不裁剪输出、不删除失败芯。
只有训练侧证据显示稳健改善才登记后续预算；本轮单折单种子不宣称目标完成。
