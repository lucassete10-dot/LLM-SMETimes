# 第五阶段：早期信号的多时间窗特征（冒烟预登记）

第四阶段外层用于开发报告，不按外层芯分别改模型。尾部加权不能保证
提前识别末期衰退；第五阶段只检查训练/验证侧的信号表示是否有帮助。
固定四家族首折、seed20261005，共8模型：相同ExtraTrees128、叶1、
尾部权重3、全局模型，各比较现有输入与追加多时间窗统计输入。
每芯96个未来训练标签上限，等芯总权重，所有标准化仅训练芯。

追加特征：前100源循环信号在(0,25]、(25,50]、(50,75]、(75,100]
的逐维中位数及标准差；前半/后半的逐维线性斜率和斜率差。
缺测窗口记NaN，只用训练中位数补值。不以终止循环或容量归一化窗口。
仅V/I及既有可用T派生信号；无测试容量/SOH/真实寿命/未来信号。
统计窗口不按单芯寿命比例改变。两候选训练数据、权重、模型、种子相同。
读取原冻结train/validation，不加载outer测试芯；本轮不作正式五折结论。
冻结验证评分与原Goal相同，所有失败保留。若验证改善再登记正式扩展预算，
否则保存失败证据，不据外层误差删芯或为指定电芯手调。
