# 连续曲线与历史长度：首轮注册

目的：验证逐点回归和连续形状输出的差异，寻找进一步搜索的输入长度范围。第一折、一种子为流程试验，之后扩展五种子及全部折；不能宣称完成最终目标或确定最短长度。

复用冻结MIT/XJTU/NCA电芯划分，仅加载当前train+validation，不读取外层test。已有公开开发结果可作诊断，不能重新称盲测。

本轮SOH改用容量/额定容量：MIT1.1Ah，XJTU2Ah，NCA3.5Ah。旧归一化标签以已有标签参考容量换算，参考只用于标签重建，不进入输入。每颗电芯记录换算因子、原参考规则和来源文件哈希。旧初始容量归一化下指标不能与本轮绝对误差混用。

输入只使用明确命名的V/I/T列及已知工况。四段历史中位数、变化和末段斜率；统计仅截断在origin之前。缓存NCA仅有前100次信号，当前不能声称支持>100次历史。

候选固定：逐点ExtraTrees VIT叶1；连续曲线ExtraTrees VIT叶1/3；连续曲线V叶1；仅工况连续曲线叶1（消融）。均80棵、相同种子、训练侧中位数填补和尺度归一化。每个候选保存模型、预测、指标、配置与耗时。

连续曲线 a-b*h-d*g(h,tau)，h=(cycle-origin)/100，g是平滑正部平方；b,d非负，允许d=0近似线性。训练电芯自身标签用NNLS及固定网格拟合曲线监督，测试电芯仅由早期特征预测参数。不使用未来真实寿命定位tau。该候选保证长期下降与斜率加速，不能表示全部真实恢复/减速，因此保持逐点基线并检验模型偏差。输出不裁剪，不做末值延长。

长度可选10/20/30/50/75/100；每次实验明确传入。共同电芯交集、共同>max(100,最大输入长度)未来区间公平对照，报告所有不可用电芯及原因。另需后续实际起点任务；当前不能以共同区间代替最终实际使用评测。

主选分数：MAE_pp + 末20%MAE_pp + 阶段下降误差_pp + 归一化MAE + 加速反向惩罚。诊断联合标准按总方案：MAPE6、MAE1pp、末段1.5pp、阶段2pp、归一化MAE25%、无加速反向；可信拐点检测单列且须完善后才可宣称最终联合达标。

核验：电芯互斥、数据哈希、模型保存重放、标签/未来信号污染不改变推理、物理族错误拒绝、输入列允许表、曲线参数仅训练电芯拟合、连续候选密集网格下降与凸性检查。目标仍未完成。
