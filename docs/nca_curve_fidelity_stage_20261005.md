# NCA曲线Goal新训练阶段

训练前固定：继承20261004T161453_449950Z的全部整芯划分及准备数据。
先NCA_fold1、种子20261005、8候选冒烟，随后固定五折五种子05至09。
候选：旧64树深度8叶片3/6/12；完整128树深度8叶片1、深度不限叶片1/4；
已知温度/充放电倍率/截止电压工况局部树，深度不限叶片1/4，
局部训练芯少于6回退家族全局模型。全部内层使用原Goal曲线评分。
不按外层失败指定参数，不修改异常过滤，不修改验收门槛。

为避免训练读取外层标签，独立无学习准备步骤将既有55芯joblib拆成
逐芯文件；拆分不拟合任何统计、不改变特征或标签，保存源/逐芯SHA。
训练进程只读取本折train/validation文件，核对SHA和前100原始信号重算前缀。
前缀来自900秒V/I、前100循环统计及已知工况；没有Q、SOH或寿命输入。
预测查询使用绝对源循环，不使用真实寿命归一化；测试标签只用于后续评估。

保存每轮配置/划分/数据源码SHA/真实日志/权重/完整验证预测与四指标。
标签移除/前缀原始信号重算/家族门控必须核验。全部外层仍未见的本折
电芯和高误差正常电芯保留；当前公开开发CV不称盲测。
