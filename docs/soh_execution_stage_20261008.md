## 实验发现与处理决定

1. 直接预测连续退化参数并不能自动提高精度。其虽约束下降方向，部分电芯后期误差很大，因此不替换冻结基线。
2. 衰减速度积分能够生成非回升趋势，但平均误差目前没有稳定胜过逐点基线。MIT、XJTU和NCA的候选全部保留作对照，不因为曲线连续就判成功。
3. HUST点基线平均MAPE约2.3%–2.6%，速度积分约3.1%–3.4%；目前所有候选严格开发筛查通过率均不足目标。不能宣称已找到可靠输入长度。
4. 精确重建ExtraTrees叶节点权重发现，连续参数候选的短寿命训练电芯，即使权重很低也可能以巨大曲率影响长跨度预测；非线性参数平均与曲线平均也不等价。这是具体实现/输出结构证据，不是笼统归因于特征错误。
5. 新候选已测试曲线空间叶权重平均、仅依据训练支持范围的线性尾部延伸以及独立起点模型；不使用验证未来容量或寿命进行校正。6个候选均已完成并保存；XJTU连续V候选平均MAPE从6.76%改善到3.43%，但仍弱于点基线1.34%，所以不采用为当前最强模型。该候选仍需完整独立核验。
