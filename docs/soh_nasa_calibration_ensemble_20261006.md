# NASA早期信号校准集成：训练侧固定预算

本阶段落实个性化预测中的起点/速度稳定性检查，不改变主Goal及其验收。
不能为指定外层失败电芯手工校正，也不使用未来容量、真实寿命分型。
先不加载外层电芯。沿用已独立核验的Stage49及其Stage47训练侧权重。

保留61个既有候选，新增18个：校准器成员absolute六个、delta六个、
全部十二个；聚合mean/median；趋势权重0/0.25/0.5。共79，预算先固定。
聚合早期信号推断的101循环起点及直接趋势。预测为
(1-w)*(原Ridge曲线+聚合起点-Ridge101起点)+w*聚合直接趋势。
统计聚合不接触查询标签；不是把测试曲线拟合得更好。

各父折仅原train+validation三芯内部轮流留一，每次两个训练芯。
同原评分选模；对照为Stage49该父折锁定选择。新增候选只有在至少
3/4父折改善评分、至少两折选新增集成、平均终点/下降误差不退步且
MAPE不增加超过0.1百分点时，才扩展正式外层重训。筛选未过不放宽。
保存2844条训练/验证曲线、逐芯指标、继承SHA、配置、日志及独立核验。
本轮是继承权重变换，新增组件训练次数为0，不包装成新训练结果。
三芯内部结果有重叠，不当作12个独立电芯。NASA短预测跨度继续标注。
