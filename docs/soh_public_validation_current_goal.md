# 当前有效目标：公开数据同类型新电芯未来SOH预测

依据用户2026-10-04最新澄清：当前验收不需要STM32板卡、上板实测或用户额外新数据。STM32只作为未来轻量化方向；旧部署目标和交付保留，不再阻塞当前算法实验。

MIT、XJTU、NASA分别按物理家族和整芯冻结划分评测。使用前100源循环V/I及可用T、已知工况预测其后SOH，不输入测试电芯Q/SOH/未来信号或真实寿命。每芯先算MAPE、等权汇总，至少5种子；NASA4芯使用LOBO及内层验证，明确小样本与已反复观察公开测试的开发性质。

当前优先改进NASA到MAPE约6%或更低，并完整保存逐芯误差与失败，不按误差删除电芯或事后改归一化。MIT/XJTU既有正式结果保留。

用户同时授权检索并下载适合V/I预测未来SOH的其他优质公开电池数据集。先核查来源、许可、物理规格、原始信号、容量标签和寿命采样覆盖，再新增独立类型与整芯验证。不能把不同规格电池混成NASA类型，不能用容量-only数据冒充V/I输入；下载与训练完成分别记录。

不承诺调参一定达到6%。所有新结果仅训练/验证选参，冻结外层测试作开发评测；真正独立新电芯以后可做额外验收，不是现在的前置条件。

## Goal与范围

完成MIT、XJTU、NASA同类型未见电芯的未来SOH预测开发验证，核心目标为各自电芯等权全未来MAPE≤6%；优先补齐NASA改进方案的曲线、逐芯四指标、后期误差与输入泄漏核验，再引入新的优质公开数据集独立训练验证。模型可以按家族不同，不要求一个权重跨化学体系通用。

实时SOH估计、RUL、STM32上板、量化及用户新电芯独立盲测均不是本阶段前置条件。禁止为达到数字更换外层划分、删高误差电芯或用测试结果挑某折模型。

## 固定验收标准

1. **预测合同**：前100源循环内V/I、可用T及已知工况，预测之后全部有效观测SOH；SOH为容量/初始可比容量、0–1比值。测试电芯容量、SOH、真实寿命、未来信号不能参与预测输入。初始参考容量只建立评测标签，不提供给预测器。
2. **类型合同**：物理规格/原始实验队列决定家族，工况为单独变量。未知型号不因曲线相似自动视为同型；NASA保留未核实型号限制。新增家族不可自动并入MIT、XJTU或NASA。
3. **整芯合同**：MIT/XJTU冻结整芯5折、内层验证；NASA4芯冻结LOBO、内层验证。每芯每种子恰好测试一次。归一化、特征选择、校准只拟合相应训练电芯；内层选定后开发电芯重训，外层测试始终隔离。
4. **主要精度门槛**：每芯先算全未来MAPE，各芯等权，再汇总5种子均值±样本标准差；每个数据集分别≤6%。不合并多个数据集的平均数。此为队列平均达标，不代表每颗电芯都≤6%；逐芯达标比例、最差电芯和误差范围必须同时报告。
5. **曲线质量交付**：全部正常测试电芯真实/预测曲线、MAE/RMSE/MAPE/R²、后半程MAPE、最后100源循环区间MAPE和末点绝对SOH百分点误差必须齐全。末段不足100循环时报告实际覆盖，不补造标签。R²为负、明显后期失配的电芯明确标为局限，不把平均MAPE达标描述成所有曲线贴合。当前不临时新增或事后放宽未获用户确认的后期硬阈值。
6. **质量规则**：以预先记录的完整性/物理/协议规则排除损坏或非可比记录，保存排除名单和前后数量。正常短寿命、恢复、误差大不剔除。观测不足标为任务不适用及覆盖缺口，不偷偷删掉后报全覆盖。
7. **统计诚实**：随机模型至少5种子。确定性Ridge可重复5次核验，但零种子SD不是额外独立复现或跨电芯稳定性证据；仍报告电芯间差异和全折覆盖。已有公开外层结果已被观察，标为开发交叉验证，不称新盲测。
8. **留档与复现**：每轮保存配置、输入与源码哈希、训练/验证/测试名单、候选选择、权重、日志、预测数组、逐芯指标、曲线和失败。不能以未保存曲线的临时汇总宣布完成。
9. **新增数据准入**：核验官方来源、许可、规格、原始输入字段、标签来源、源循环编号及诊断频率后再训练。只含容量或只有SOC实验的资料不冒充本任务。新增队列独立报告，不能拿更容易的数据替代NASA原任务。每100循环才有一次诊断的牛津数据，前100源循环只有约2次诊断，不能伪称100次观测；单独记录输入覆盖，必要的补充N只作为不同任务报告。
