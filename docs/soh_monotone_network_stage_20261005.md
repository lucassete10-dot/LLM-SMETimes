每训练芯一行固定cycle101的早期表示，训练芯中位数/StandardScaler。
网络Linear→Tanh→Linear(4)，隐藏宽16/32、AdamW decay0.01/0.1四候选，
lr0.001、400固定epochs、训练CPU float32，禁止使用验证早停或随机行验证。

tau=softplus(u3)。曲线a-b*h-c*[.1 softplus((h-tau)/.1)]²，h=(cycle-100)/100。
速率/加速非负，整条预测单调；a范围是结构先验而非评估后裁剪SOH，
未来输出仍可为负，不能为美观截断。tau不是输入真实寿命，是网络预测参数。
