# Stage94：TRAIN OOF工况与时距误差诊断（训练前固定）

Stage93两参数时距增益没有通过内层扩展门，不采用。下一步先判断
同家族内的工况混合是否隐藏了相反的校准需求，而不是继续盲调系数。
复用Stage92的31颗TRAIN整芯OOF预测，只加载原TRAIN，不加载13验证或
11外层。工况使用现有已知协议/放电倍率/截止电压键，不使用真实寿命。

固定输出全家族和每个工况的：成员、数量、未来覆盖、完整轨迹尾权3的
无正则下降增益、仅末点无正则下降增益、两种增益对应的OOF误差、
原OOF前半/后半有符号偏差、起点/末点/drop误差。全轨迹沿用≤96均匀
采样、电芯等权；末点同样电芯等权。增益限制[.5,2]；分母为零标记
不可辨识，不默默编造估计。数量<6标记局部支持不足，不删除电芯。

这些增益由同批OOF标签拟合后回评，只是校准诊断，不是校准器的独立
泛化成绩。逐芯输入OOF基模型未见过该电芯，但增益本身见过其标签。
不能用这张表声称模型提升，也不能依据外层失败电芯分别修正。
保存依赖SHA、源码快照、诊断JSON/日志；独立重算矩阵积和所有指标。
正式目标、扩展门与基模型不变。诊断完成后按支持和误差结构决定
工况校准或改换目标函数，不预先承诺有收益。
