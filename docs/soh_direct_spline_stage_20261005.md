# 第八阶段：直接条件化分段曲线（启动前预算）

不使用旧预测残差作训练目标，直接拟合训练芯未来SOH标签。
四家族冻结首折seed20261005，每家族固定4个Ridge候选：
训练芯前100信号PCA2/4 × alpha10/100，另保留第六阶段冻结ExtraTrees对照。
仅训练/验证芯；所有候选共16新拟合、20验证设置，不读外层标签选型。
编码器复用已审计的按训练芯一行拟合中位数/标准化/PCA逻辑。
时间h=(请求源循环-100)/100；固定基为h、log1p(h)及
max(h-t,0)^2，t∈{0.25,0.5,1,2,4,8}。这些绝对循环节点不按真实寿命变化。
输入[x_time, z, z*x_time]直接Ridge回归SOH，可拟合非线性加速和信号差异。
每训练芯未来标签最多96均匀点，等芯总权重，尾部权重3；
回归输入Scaler仅训练侧加权拟合，不对输出截断、对齐或按测试末点校正。
PCA维度min(2/4,训练芯数-1,信号维度)，NASA仅2训练芯故PCA至多1。
全未来验证观测保留，固定评分与原Goal相同。
保存源码/数据SHA、配置、权重、日志、验证完整曲线与全部失败；
独立重放训练统计、代数系数和预测。单折小实验不代替主目标验收。

## 后续全信号对照（启动前追加）

初轮16PCA候选已结束，不能因其失败把非线性曲线本身判无效。
增加同4家族首折seed20261005全信号/同分段基/Ridge alpha10和100两个候选，
不做PCA，仅训练芯一行信号补值和标准化，共8新拟合/12验证设置（含冻结树对照）。
回归LSQR tol1e-8、max_iter5000，记录收敛迭代、求解残差核验。
不改节点、不据外层选择、不替换当前较强模型直到训练侧证据充分。

全信号首次8拟合完整结束且129验证曲线独立核验，但NCA标准化过程中出现
近常量列浮点sqrt警告。相同4家族/参数/种子/名单原样重跑8拟合，仅将
回归矩阵训练加权方差先减固定训练首行offset，再恢复均值用于推理。
此为数值修复重复，不是新增候选或独立种子；不裁剪方差/SOH，不改数据。
