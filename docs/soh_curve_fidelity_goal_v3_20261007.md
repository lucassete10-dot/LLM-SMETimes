# SOH未来曲线贴合目标 v3

电池未来SOH曲线贴合改进（v3，2026-10-07）：在现有工程和公开MIT134、XJTU55、NASA4、Zhu2022 NCA55电芯基础上优化算法，优先实质训练与验证，不以整理图表代替优化。只做同物理类型未见电芯的未来SOH预测，默认输入前100个绝对循环的电压、电流、可用温度及已知规格工况；保持现有输入合同，是否允许早期容量/SOH须按现有代码审计结果明确记录，禁止偷偷增加部署不可得的容量真值。不同化学体系/规格/工况独立建模或严格分层路由，禁止MIT与NASA混为同类型，不能用测试未来寿命定义400/800循环类型。保留历史模型、结果和全部失败记录，以results/four_cohort_goal_curves/20261007T112211_343981Z及独立数值表results/goal_v2_tables/20261007T111732_433233Z作为冻结比较快照，不将旧未采纳候选冒充已采纳模型。

首先诊断原始数据质量与模型错误：MIT b1c0低谷仅是待核查信号，逐点核对原始放电V/I/时间、截止电压、协议/中断/积分容量；仅据事先确定的物理/完整性规则移除确证无效记录，不能因预测误差大删除电芯。数据不足单列，无法确认的低谷保留；原始标签与清洗标签分别保存、报告，禁止靠平滑真实曲线伪造贴合。b1c2重点诊断衰减速度高估与累计偏差；b1c3重点诊断阶段/曲率错误（真实早期慢后期加速，预测中段快后期变平），不能用终点接近宣称趋势正确。这三颗已看过的电芯仅作问题示例，不针对它们的未来真值调参。

训练与选择严格按物理电芯分组：固定外层留芯/5折、内层验证选特征/模型/损失/异常阈值，5个种子，预处理和路由仅拟合训练电芯。公开外层结果已反复查看，称开发CV而非盲测；不得针对外层误差反复选模型。先MIT训练侧小规模冒烟及验证，验证通过再扩展四队列。优先核查早期归一化锚点、与类型对应的充放电特征、斜率/加速度及同类型退化模板支持，比较分层模板/时间尺度回归、锚定的分段或样条退化模型、轻量序列/残差模型；损失同时关注点误差、各阶段下降量及加速退化，不能强制单一线性趋势或在输出端使用未来标签校正。不强制LLM获胜，采用验证上更优的可复现模型。

新的曲线贴合验收：不再沿用旧MAPE<=6/终点8pp的宽松联合标签。逐电芯五种子平均满足全段MAPE<=6%、MAE<=1个SOH百分点、最后20%有效未来观测MAPE<=2%、终点绝对误差<=2pp、总衰减幅度误差<=2pp；同时衰减尺度归一化MAE=MAE_pp/max(abs真实未来总下降pp,2pp)<=25%。将有效未来范围等分为三个绝对循环区间，计算每段边界附近固定窗口稳健SOH下降量，预测与真实各段下降差均<=2pp，并报告加速/减速方向错误；对超出噪声容差且真实有明确后期加速的电芯，预测错误方向即形状失败。阶段窗口、噪声容差与拐点检测协议必须先用训练侧定义、保存后锁定，不能在看外层结果后改阈值。仅当完整未来覆盖足够且存在可信拐点时评价拐点位置误差，目标<=有效未来跨度20%；没有可信拐点/覆盖不足不强制臆测，不可简单标达标。

目标完成须四个队列分别至少90%合格且覆盖充足的正常电芯满足上述点值与形状联合标准（NASA4颗要求4/4），每队列相对冻结快照的宏平均MAE、终点误差和阶段形状误差不恶化；所有适用原始电芯、剔除/不足覆盖原因和实际覆盖率必须完整报告，不能筛选容易预测的电芯抬高达标率。原始标签上全段宏MAPE<=6%仍是底线。未满足则目标未完成，诚实指出数据可预测性及剩余失败；不承诺每颗未来随机尖峰均可准确预知。

采用多轮假设驱动优化：不设全项目仅两次新实验的机械限制；每轮先注册少量明确候选及等额验证预算，训练-验证筛选，冻结选型后完整外层评估。失败则总结训练侧证据后提出新假设，不做外层驱动的随机调参。每次训练完成立即独立保存配置、数据/代码SHA、划分、种子、日志、权重、逐点预测、指标、训练时间/参数量和判定，失败也保存。报告五种子样本均值±SD，确定性重复不伪装随机不确定性。工程交付新旧同轴曲线248张+4总览（数量随有证据且事先锁定的任务适用性审计清晰列示，不偷偷减电芯），完整逐电芯/逐种子Excel及异常审计、可重放脚本、完成/未完成结论；重绘不等于模型进步。STM32、RUL、实时估计、新数据集暂不在范围。
