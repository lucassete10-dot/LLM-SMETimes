# LLM＋SMETimes 曲线预测优化 v4：五数据集轮流诊断与有限对照

用户已授权按“尺度与起点诊断 → 曲线预测头优化 → 尾部损失优化”开始执行。参考 all_TRAIN_curves.pdf 的贴合程度及此前认可的 MIT b2c14/b2c17 预测图；PDF 是 TRAIN 拟合参考，实际预测能力以隔离电芯评估。

## 目标和输入

MIT、XJTU、HUST、UConn_ISU_ILCC、Zhu2022_NCA 均参与。沿用真实预训练 Llama＋SMETimes 数字/文本融合和专家路径；输入为前100实际源周期可见信号与预先已知工况。缺失通道保留掩码；UConn 按实际稀疏 RPT 点评价。保持源数据、划分、TRAIN 拟合预处理器和 v3 验证评分，所有图保留真实标签。

主验收：每颗电芯每个种子 MAPE≤3%，种子20260930/31/32；同时报告 late MAPE、起点、终点和阶段下降误差。曲线参考指标沿用 MAPE≤1.5%、late MAPE≤3%、起点≤1pp、终点≤3pp、阶段≤3pp。缺失阶段证据记为不可评价。真实近线性电芯允许线性预测。

## 执行次序与上限

1. 五数据集首折已完成的120轮上限 R0 逐一诊断。独立重拟合 TRAIN scaler 对比，检查有限观测和缺失比例、标准化异常值、起点误差、速率节点变化和局部恢复饱和。仅读取 TRAIN/VAL 预测和可见历史；标签/未来污染测试必须通过。诊断结论限定为量化症状，不能直接宣称因果。
2. 预登记两项有限候选，每项都按 MIT→XJTU→HUST→UConn→NCA 执行。K 仅增加固定物理速率节点的时间分辨率，保留解析积分和局部恢复；节点固定为 horizon/100 cycles = [0,.05,.1,.2,.25,.35,.5,.75,1,1.5,2,2.5,3,3.5,4,5,6,7,8,10,12,14,16,20,24,28,32]，不按目标电芯真实寿命设置。L 仅调整 TRAIN 损失组：阶段/窗口下降权重 .5→1，尾部权重 .5→1.5；起点和全程权重保持1。K与L分别对照 R0；本轮不自动叠加。
3. 筛选使用20260930，最多120轮，至少40轮，每10轮验证，4次未达到相对0.5%改善早停。复用相同预算 R0，所有新模型从同一预训练主干初始化。新增筛选最多10次。
4. 候选 S_val 至少改善5%、MAPE≤3%通过电芯数不下降、最差MAE≤R0的1.1倍才进入三种子确认。并列时依评分，再按K/L顺序选。每数据集只确认一个候选，最多240轮、至少60轮、patience6；复用 v3 相同预算 R0 三种子。至少2/3种子改善、均值改善5%且每种子保护条件成立才能采纳。
5. 有效候选才扩展原有其他折、补齐3种子。每个新折独立使用 VAL 选检查点；候选选择锁必须先写入，再评估原 TEST。已有 TEST 已查看，继续标记开发评估；当前源队列没有可凭空宣称的新盲测电芯。真正外部确认需后续新增未见数据。
6. 全部失败则保留 R0，并交付负结果。成功数据集生成完整 TRAIN/VAL/TEST 图集和3种子指标；筛选及确认仅生成 TRAIN/VAL。所有实际运行持久记录设置、源代码哈希、模型哈希、重载及查询/标签/未来隔离证据。生成图后视觉检查状态须准确标注。

新训练最大61次：10次筛选＋最多51个被采纳候选的正式折×种子；首折确认复用为正式槽位。未达筛选条件不追加轮数、不反复在单个数据集调参。GPU串行、运行可恢复、失败停止并写日志；完成有限实验与达到全部精度目标分别报告。
