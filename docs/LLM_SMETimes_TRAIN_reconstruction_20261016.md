# TRAIN完整曲线重建执行方法

当前授权先做TRAIN。完整训练寿命的V/I/T/time特征用于重建同一时段SOH，区别于之前的前缀预测；未来观测在重建任务中允许使用，但SOH/容量/EOL/电芯ID不作为输入。只使用原首折TRAIN的240颗电芯；不训练、评估或按VAL/TEST选择模型。本轮不开展前100预测或蒸馏。

保留真实预训练LLM、统计文本与数值自适应融合、SMETimes专家。沿真实观测划分窗口：每60条中心观测带前后各20条上下文，最多100条，不丢弃尾部。统计文本为窗口内信号的全局摘要，经过冻结LLM后与数值patch融合；学习的数值输入仍经过实际预训练LLM。每5条patch保留位置槽，直接监督对应SOH，不再使用长程速率和有界局部修正头。稀疏RPT只保留真实坐标，不虚构100条观测。所有有效原始SOH标签均保留，不平滑。

先固定XJTU原TRAIN前三颗（含用户指出的battery-7）做小规模拟合诊断：12轮联合学习数值适配、专家与重建头，然后固定编码路径，缓存其无标签真实输出，仅优化共享重建头至最多200轮；若诊断明显失败，先定位修复再扩展。缓存不是替代模型，最终重载实际LLM重新计算并核对缓存重放；不同电芯没有独立拟合参数或查表。

正式首轮MIT→XJTU→HUST→UConn→NCA，每个12轮联合训练＋最多200轮低成本共享重建头细化。头部细化采用TRAIN宏平均MAE选择，30次检查无改善可停止；只优化重建头时编码器明确冻结，不能宣称该阶段仍在更新LLM/专家。各芯总监督权重相同，窗口按真实标签数分配权重。无dropout、无权重衰减，先诊断拟合能力；不以防过拟合为由掩盖TRAIN欠拟合。

优化参考：TRAIN平均MAE争取≤0.5个百分点、MAPE≤1%，同时报告逐芯误差、尾段、终点与形状；这些是诊断目标，不承诺每个噪声点完美重合，也不增加用户的预测验收门槛。训练完成和图集导出不等于拟合成功。

图集问题：完整输入下模型能否重建每颗训练电芯的原始SOH？每芯一页实测/重建曲线，黑色原始标签、蓝色重建，单种子无SD/CI；明确标注完整寿命输入、TRAIN重建、非预测。沿用Python图形风格，输出PDF/PNG/SVG并检查文本、碰撞与每页可读性。Markdown结果表直接链接各数据集PDF与逐芯CSV，列明张数，不默认ZIP。保存模型/源代码/数据索引SHA、训练过程、梯度、全部标签覆盖与无标签输入检查。
