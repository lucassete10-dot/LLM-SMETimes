# 第十阶段：训练侧暖启动单调网络（启动前预算）

上一阶段网络tau初始化0.2，MIT训练预测tau中位约0.22，而同族训练标签
拟合tau中位4.06；不能将此前网络失败直接归因于曲线表达能力不足。
本阶段仅改变训练初始化/优化长度，不增加测试信号或容量输入。
四家族冻结首折seed20261005，width32/decay0.1固定，400/2000epochs两候选，
lr0.001，其余权重、前100信号、单调曲线与等芯尾部3均与第九阶段相同。
每训练芯96未来标签点，31个绝对训练坐标knee网格，用有界线性最小二乘
拟合同一平滑曲线族a∈[0.5,1.25]、b/c非负。只用train，不用validation。
取训练芯a/b/c/tau各维中位作为共享初始化。最后层权重初始化零，
偏置用上述参数的激活逆变换；a sigmoid分数只在初始化限到[1e-6,1-1e-6]，
b/c/tau初始化下限1e-6避免log0。不是对最终预测SOH作截断。
拟合参数只是监督训练初值，不是测试输入，推理仍从早期V/I等预测所有参数。
8网络训练/12验证设置（含冻结ExtraTrees对照），每模型400/2000固定训练，
不验证早停；不扩大成全折除非固定验证评分有改善。NASA对照不等于强Ridge。
保存训练侧拟合每芯参数/初值、模型state、全部epoch loss及完整验证曲线。
独立重训、标签/未来污染、训练统计与曲线指标重算。所有失败保留。
