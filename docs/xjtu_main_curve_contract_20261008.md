# XJTU阶段主图

问题：当前模型利用前100源循环已观测的电信号，对44颗留出开发电芯的未来SOH预测贴合程度如何？每颗单独一张，真实与预测同坐标比较。

复用本项目MIT主图的Python结构，数据来自最新已复核core_length_cv五折结果。source_cycle→横轴；truth与prediction→SOH(诊断容量/额定2Ah)。不插值、不平滑、不裁剪，不删失败电芯。此次一个随机种子，不绘制虚假的种子SD或置信带。

单面板定量曲线，8×5英寸报告版、PNG300dpi、PDF可编辑文本。每张执行字体与碰撞检查，记录人工审图范围。不宣称期刊规格已确认。ZIP按XJTU/电芯名.png组织，与用户指定格式一致；原始数值、模型、QA仍存项目目录。

100次输入为阶段选项，非已证实可靠最优值。44颗电芯是留出开发验证，不是独立测试，曲线形状成功不因MAPE低自动成立。
