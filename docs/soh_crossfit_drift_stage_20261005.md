# 第六阶段：训练芯交叉拟合的漂移校正（小规模预算）

固定四家族首折、seed20261005。复用冻结train/validation，无outer芯读取。
基础预测器固定ExtraTrees128叶1尾部权重3全局，非按测试表现选型。
训练芯以该种子打乱分成两组；每组的残差来自不含该组的基础预测器。
每芯最多96未来标签点，残差目标y-p_oof，等芯总权重/尾部权重3。
验证芯完全不参加基础拟合、残差拟合、补值或标准化。

残差头只用请求源循环的h=(cycle-100)/100，不能使用真实寿命比例。
固定四候选：不校正；一次h/Ridge alpha10；二次h/Ridge alpha10；
二次h/Ridge alpha100。StandardScaler仅拟合OOF训练残差坐标，Ridge有截距。
同一基础模型、同一OOF残差用于四候选，隔离是否系统性漂移的效应。
无SOH裁剪、无强制斜率、无手动末点对齐，无测试误差校正。
至少两训练芯才执行交叉拟合；NASA两训练芯故每次基础仅一芯，明确高方差。
四队列各3基础模型（2OOF+1全train），加3残差头，共24次拟合、16验证设置。
按既有固定验证评分比较，全量扩展需另行登记；本轮仅冒烟，不宣称达标。
保存每个OOF模型/名单/全部采样坐标truth/prediction/头/验证完整曲线/真实日志。
来源SHA固定，重算残差、训练统计、预测、误差、未来污染及家族隔离。
