# v2.1 多视角有限试验：训练前登记

状态：已登记，尚未观察候选训练/验证结果。不宣称精确复现论文。

选择MIT作为首轮队列，依据其134颗电芯、已核验V/I/T输入、物理类型
证据及训练支持，而非外层误差。复用MIT_feature_blend_outer配置的
五个整芯折及20261005–20261009五种子，仅载入每折train/validation，
不载入test。两配置计入MIT本轮2/2预算，无第三配置或额外搜索。

输入：复用mit_segment_features的VIT允许列，排除Ah/Wh；首100源循环
的初始/末期统计为状态视角，差分/OLS趋势/四段统计为演化视角，
覆盖范围及已知工况为第三视角。列清单与维度自动记录。缺失填补
及标准化只用train电芯拟合，允许空列以0填补并显式记录。

配置C0：三个小编码器（各16维，Linear+Tanh），拼接后输出。
配置C1：相同编码器，额外三路softmax门控，对各视角加权后拼接输出。
共同曲线头：融合向量+请求跨度h=(cycle−100)/100、log1p(h)、h²；
Linear(51,32)+Tanh+Linear(32,1)，SOH=1+0.1×head，确定性直接输出，
不使用真实寿命坐标、不截断到SOH=1，不按真实曲线逐芯校正。
网络参数量差异只为门控参数（147个），均记录实际值。

共同训练：CPU、Torch确定性算法、2线程、AdamW lr=0.001、
weight_decay=0.001、最多200epoch、全批、SmoothL1 beta=0.02。
每train电芯最多96个均匀未来点；电芯权重相等，后段权重1→3，
仅训练标签生成权重。每10epoch按现有内层综合score保存最优权重，
本轮不改学习率、宽度、loss或epoch预算；不使用外层早停。

对照：恢复既有MIT_feature_blend_full每折/种子的内层选择，读取其
保存的验证逐点预测重算同一score，记录哈希和划分对应关系，不按
外层成绩换对照。完整数据和预测必须对应相同验证电芯/循环/真值。
分别报告两配置逐芯结果及五种子汇总；若要求外层扩展，只用全部
内层比较锁定一个候选，精确平分保留原模型，不按外层逐芯挑配置。

冒烟：一个折、一个种子、最多20epoch，两种同配置，验证保存/重放、
输入扰动、维度、家族隔离。它不作为五折五种子结论，不允许根据
冒烟误差增加第三配置或改变预算。全量仍最多200epoch。

验证同时保存配置、模型、源码/数据哈希、权重、耗时、训练/验证
逐点数组及MAE/RMSE/MAPE/R²/后半/起末点/drop指标。没有改善则
如实保存负结果并保留旧方案。本登记不改变四队列A级/B级标准。
