## 参考图所展示的效果

图片标注：held-out-cell development CV，5个种子均值±1种子标准差；显示的 seed-mean MAPE 为0.60%，Late为0.61%，Endpoint为0.13pp，Drop为0.16pp。以上是附图标注值，尚未从对应原始预测数组重新计算。

曲线主要特征：预测起点贴近观测，能跟随前期缓慢衰减和后期加速下降，中段偏差较小，尾段与终点接近，种子间波动较小。每颗电芯应跟随自身真实趋势；参考的是预测质量，不是要求各电芯有同一形状或寿命。

## 对当前执行的作用

- 应用于 MIT、XJTU、HUST、UConn_ISU_ILCC、Zhu2022_NCA。现有 LLM＋SMETimes、首100实际源周期输入及轮流实验安排继续执行。
- 主验收仍为每种子MAPE≤3%、最终3个种子；本图作为进一步追赶的优质预测目标。每次结果应同时报告整体、尾段、起点、终点、阶段下降和种子稳定性；仅MAPE≤3%不能称为达到本图水平。
- 图中5个种子的标准差不直接等同于当前3个种子的标准差；各自清楚标记样本数，均不作为置信区间。单种子筛选不代表3种子稳定性。
- 后续结果按“达到主门槛”“与本图接近的高质量预测”“仍有形状或尾部偏差”明确说明，保留全部电芯。原图Drop与现行阶段指标的具体计算口径，在找到对应原始运行后核对；不凭截图建立未经核对的精确联合通过判定。
- 候选仍由TRAIN/VAL比较确定。对已查看的TEST继续标为开发评估；图像和未来真实标签不作为目标电芯推理输入。
