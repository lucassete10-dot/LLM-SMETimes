# TRAIN重建头稳定优化补充登记

首次全量XJTU的TRAIN宏平均MAE0.834pp，battery-7 MAPE2.252%，小规模三芯却达到约0.48%平均MAPE。共享模型仍存在明显偏移，固定学习率的随机小批量头部更新也出现评价振荡。本补充仅优化TRAIN重建，不能据此宣称预测改善。

等五数据集首轮全部结束后，依次检查。对宏平均MAE>0.5pp、任一电芯MAPE>3%或终点误差>3pp的数据集，固定其原已学习的数值/LLM/融合/专家编码器，从原TRAIN最优模型开始，使用同一份无标签特征缓存，最多80步全TRAIN确定性L-BFGS（共享重建头、强Wolfe线搜索、历史10）。其余数据集保留原模型，不重复训练。阈值用于优化优先级，不是用户新的严格验收门槛。

损失仍是等电芯权重的真实SOH点误差。全量梯度在多个批次累积，避免随机小批量带来的水平漂移；不给电芯独立参数，不添加ID，不把SOH放进特征，不改原始标签或平滑曲线。每5步核对TRAIN宏平均MAE；只保存低于原模型的候选，否则保留原模型。对不改善的情况不反复追加预算。
