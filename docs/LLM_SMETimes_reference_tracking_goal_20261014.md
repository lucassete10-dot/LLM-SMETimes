# 持续检查与预测曲线优化 Goal（2026-10-14）

用户授权：当前训练结束后继续工作，自主检查训练和模型，朝 XJTU b1_2C_battery-4 参考图的预测质量靠齐。

## 本 Goal 的可执行范围

完成正在运行的 v4 五数据集有限队列，持续检查日志、实际进程、梯度、早停、模型和重载证据；每完成一个模型，就核对同预算 TRAIN/VAL 指标和真实曲线。训练完成后继续完成结果审计、所有新图的实际视觉检查以及一次根据证据登记的有限后续优化轮。不是在训练结束时停止工作。

沿用 LLM＋SMETimes、前100实际源周期输入、真实源标签和现有物理电芯划分，最终3种子20260930/31/32。五数据集依次轮流：MIT、XJTU、HUST、UConn_ISU_ILCC、Zhu2022_NCA。GPU串行，重复检查不能重复启动同一个训练。

## 参考目标和验收解释

主要质量参考：[参考标准补充](D:/LLM/SMETimes-main-WINDOWS/docs/LLM_SMETimes_v4_prediction_reference_20261014.md)。图中文字：seed-mean MAPE0.60%、Late0.61%、Endpoint0.13pp、Drop0.16pp，5种子标准差。尽可能让各电芯的起点、整体曲线、转折、尾段和终点贴近自己的真实观测，并降低种子波动。查找对应原始预测和绘图代码，核对原图Drop等计算口径；找不到时明确只确认图片标注，不能宣称精确复现。

主验收沿用每种子MAPE≤3%。质量参考沿用已登记的曲线实用指标并单独与图片比较；3%通过不能替代“接近参考图”的结论。稀疏数据按实际观测点评价；不可用阶段证据不补为零。任何“全部达到”结论必须有逐电芯、逐种子结果和图证据。

## 队列运行中的检查

1. 读取 status、queue、训练 history 和进程命令，区分运行、训练完成、重载核验、绘图完成和视觉已检查。技术失败先定位并修复，再恢复；不能伪造进度或把不合格模型当作技术失败删除。
2. 检查 loss、梯度和有限数值，确认真实LLM历史路径参与预测。检查 source/model/scaler 哈希、TRAIN预处理器和原始观测一致性、标签/未来污染与查询顺序隔离；仅使用VAL选择检查点及候选。
3. 当前K/L筛选及三种子确认遵循 v4 原登记规则与预算，不在运行中改训练源码、超参数或评分。临时中间曲线可以查看，正式对照用实际最小VAL评分检查点。
4. 每个完成的候选导出真实TRAIN/VAL曲线，用原始预测重新算整体、late、起点、终点、阶段指标，标出起点漂移、过早下降、尾段过平、转折错位和种子不稳。保留失败电芯，逐图检查并保存被检查PNG的哈希。已查看TEST只作开发评估。

## 当前队列完成后的工作

1. 完成 v4 候选比较、选择锁、有效候选其他折的3种子训练和开发TEST评估。核验原始预测、完整电芯覆盖、检查点选择、三个种子一致性和图表口径，复用可信R0结果。
2. 基于TRAIN/VAL诊断及K/L真实结果，预登记一次有限后续轮，最多2项互不叠加的候选，优先解决实际存在的起点偏移、转折/尾部表达不足。候选必须说明改动、证据、对照、保护条件和预算；技术实现后运行必要的行为测试。禁止只因为曲线不合格而无限追加轮数。
3. 后续轮先在五数据集首折单种子轮流筛选，每项最多120轮、min40、eval10、patience4、相对改善0.5%。最多10次筛选。每数据集只允许最佳有效候选进入3种子240轮确认，min60、patience6，最多15次；总新增上限25次。必须提供同预算、同折、同种子对照；若缺少所需对照，先减少候选数量以留出对照预算，不能把不同预算结果称为单因素收益。
4. 至少5%验证评分收益且MAPE≤3%通过数不下降、最差MAE不超过对照1.1倍才能进入确认；三种子至少2个改善、均值改善5%且逐种子保护通过才能采纳。没有收益则保留更好的已核验模型并记录负结果。后续轮的其他折扩展另列剩余工作，不额外突破25次预算。
5. 汇总五数据集最终最佳已核验模型、全程/尾部/阶段/种子表现、每张新图和失败清单，明确哪些达到3%、哪些接近参考图、哪些仍有偏差。预算执行完成和精度达标分别判断；有限实验结束不能宣称全部预测达到图片水平。
