# 最终权重开发拟合曲线合同

这些图回答：最终部署树权重在全部公开开发电芯上的未来曲线拟合在哪里失败？它们不回答未见电芯精度，也不用于再次选择超参数。

- 单图一颗电芯，定量曲线诊断；全部有效的100源循环之后观测点均显示，不平滑、不插值、不按误差删除电芯。
- 黑色实线是可比容量归一化SOH；蓝色虚线是冻结最终权重预测。输入仅前100循环信号、已知规格/工况和请求循环数。
- 193颗电芯全部属于这些最终权重的开发训练数据。一个发布种子，不画虚构的种子标准差；与五种子整芯交叉验证分开。
- 单图183×100毫米，正文8pt，所有PDF文字至少5pt。PNG用于预览，PDF/SVG保留文字；源预测NPZ和逐芯指标保留。
- 全未来、后半程、最后100循环和末点误差记录；末点绝对误差单位为SOH百分点。
- 沿用冻结完整性清单；跳过情况必须逐项记录。正常高误差曲线保留。
- 导出前记录单面板对齐不适用，导出后检查PDF字大小、碰撞；自动检查不等于全部人工审图。人工审图状态单独记录，不虚报通过。
- 补存输出使用独立目录，记录模型和源数据哈希，不修改历史权重、交叉验证或发布清单。
