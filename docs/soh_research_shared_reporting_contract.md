# 共享输入跨域结果的统计与证据合同

## 范围

此处比较的是共享输入的跨数据集研究，不是已见同物理类型部署。MIT、XJTU/NASA的规格与电化学体系仍分别登记；研究迁移不能改变物理兼容门禁。原同类型主结果、跨工况结果和本表单独报告。目标侧校准为空的零样本研究不能与目标侧拟合结果合并。

`battery_smetimes/research_transfer_reporting.py` 为纯结果整理；`scripts/report_soh_research_shared_v5.py` 为独立只读审计/输出入口。正式输入必须为明确的一份完整 baseline run 和一份完整 neural run，均是真实成功拟合、非烟测、非prepare-only。各自的预算仍由原主合同及完整静态审计核验，不能通过报告代码更改。报告不拟合、不选择参数、不加载模型权重、不证明可执行权重重放；后者使用单独重放入口。

```powershell
.venv/Scripts/python.exe scripts/report_soh_research_shared_v5.py --baseline-run <完整正式baseline目录> --neural-run <完整正式神经目录>
```

## 进入比较表之前

两组必须共享相同准备输入/配置/清单/角色指纹、主来源绑定、20/50/100源循环、五个或以上唯一种子、特征schema与名称、两个方向和源/目标电芯角色。baseline须包含Ridge/ExtraTrees；神经须包含GRU、统计MLP、预训练E1和全随机E2，总共60个最终单元。schema相同才有同输入比较资格；不能因维度相同合并120秒VI与cached VIT实验。

先核验原主全量完成及数值审计，重新派生当前共享原始输入，再独立复核两份完整run及所有单元的源候选/源CV/固定refit/目标静态证据。读取目标指标和NPZ前后核验指纹；单元审计必须匹配完整run记录，父配置、进度、run审计在整理期间也不能变化。报告者使用当前独立observer，保存其源码副本及摘要；不能宣称observer是原模型的冻结推理实现。pickle/Torch权重均不反序列化。

## 统计口径

评测单位是电芯，不是每个循环或每个训练种子。先分别计算每颗电芯的RMSE、MAE、MAPE、R²，再等权平均电芯误差；不同未来曲线长度不改变电芯权重。对每个种子形成电芯宏平均，再报告这些宏平均的均值与样本标准差（ddof=1）。这个标准差描述训练种子变化，不是总体置信区间；种子并未增加独立电芯数。Ridge等确定性重复得到零SD并不增加证据。

源域CV仅用于选参，最后全源refit得到每方向/模型/种子的一个固定模型。源CV折不是目标域的测试折或独立重复，因此跨域表不把源折误差当目标变异。逐芯种子均值与SD、芯间描述性差异、最差电芯、逐芯种子均值MAPE≤6%的比例都保留。正常高误差电芯不能排除。恒定真实曲线等情况下R²未定义时保留缺失，并报告各指标实际定义种子数及缺失电芯/种子对数，不写成零。

这里不进行显著性检验或宣称某模型显著优越；数据集批次/工况相关性仍可能存在，不根据描述性SD推断总体推广。公开历史数据已查看，当前结果属于开发验证，不是独立盲测或事先注册的实验。

## 可用循环数与覆盖

每方向/起点/窗口独立根据原输入完整性、容量参考建立时点和可观察目标网格推导可评测电芯。模型结果必须完整覆盖这些电芯与种子；不能把正常难例改成skip。+10/+50/+100区间缺少诊断容量目标时单列原因，不把“没有目标”写成“误差为零”。所有起点/窗口都报告完整目标数、可评测数、覆盖比例和逐芯缺口。

除180个方向/模型/起点/五窗口汇总条目外，另输出36个配对条目：固定20/50/100均可用的目标电芯，且各起点只评估源循环100之后完全相同的真实目标网格和SOH。网格或真值不一致时拒绝。这避免把电芯组成或未来区间改变冒称更多早期数据改善了预测。配对覆盖率也相对于完整目标队列，不能只报保留后的样本数。
