# 同类型未见电芯未来SOH：曲线贴合改进Goal

设定日期：2026-10-05。用户授权检索、制定验收标准、设Goal并训练。
此前平均MAPE Goal已完成；本Goal不覆盖实时估计、RUL或STM32部署。

## 任务与边界

核心MIT/XJTU/NASA分别训练和验证；新增Zhu2022 NCA独立报告，Oxford
保留稀疏诊断补充、不混成密集V/I主结果。复用冻结外层整芯划分。
输入前100源循环内V/I、可用T、已知协议，预测其后全部有效观测。
测试Q/SOH、未来信号、真实寿命、测试曲线拟合参数不输入预测器。
家族由物理规格决定，工况可以建局部模型但不得按真实寿命分类。
正常高误差芯不能删除。现有公开测试已看过，结果均为开发CV，非盲测。

## 固定数值验收（训练前写入；失败不能降低标准后宣布完成）

每队列电芯等权、随机模型至少5种子；先对每芯5种子误差求均值。
SOH为0–1，误差百分点pp=100×SOH绝对差。阈值是本项目工程目标，
不是声称文献公认的通用标准。

1. 全未来队列平均MAPE≤6%，后半段平均MAPE≤6%，逐芯RMSE均值≤0.04。
2. 队列末点绝对误差均值≤5pp，下降幅度绝对误差均值≤4pp。
   下降幅度误差=100×abs((p_first-p_last)-(y_first-y_last))。
3. 至少90%电芯同时满足：全未来MAPE≤6%、后半段MAPE≤8%、
   末点绝对误差≤8pp、下降幅度误差≤5pp。NASA只有4芯，此规则意味着4/4。
4. 严重平台失配比例≤10%：真实首末下降≥5pp而预测下降不足真实的30%，
   或真实下降≥5pp而预测首末回升。此项仅评测，不能用于筛除电芯。
5. 相对冻结旧模型，末点及下降幅度误差P90至少下降20%；如果旧值已≤3pp，
   则新值保持≤3pp即可。全未来MAPE不能比旧模型增加超过0.5个百分点。
   稀疏Oxford只补充报告，不作为此主目标完成条件。
6. 每芯保存四指标、后期、末点、下降幅度、曲线和失败名单；正常电芯全覆盖。
   测试点不足10、未来跨度不足100单独标识，不能用短曲线冒称长期能力。
7. 输入标签移除/未来污染、训练侧归一化、整芯划分、选参隔离核验通过；
   配置、源码/数据SHA、权重、真实日志、全部预测保存。全部曲线核验完成。

以上核心及新增密集队列分别验收。任一未通过，Goal保持未完成，如实记录
瓶颈；不能以平均数、漂亮样例或任意电芯自动分类替代完成条件。

## 选模（仅内层验证，预算固定）

同一验证评分：平均[全未来MAPE、后半段MAPE、末点pp、下降幅度pp]，
加0.25×各芯该分数P90。所有项单位为百分数/百分点，权重预先固定。
每折按此评分选择，不按外层电芯挑模型。老小树也参加同一验证比较。
小规模先固定XJTU_fold1，仅加载其train/validation，不读取test标签。
通过冒烟后扩展全折/5种子；完整外层结果只作开发报告。

## 首轮方法与实施顺序

审计旧模型压缩约束与已知工况覆盖；保留原基线。比较：
1. 完整早期特征的ExtraTrees，不限制24特征/64KiB，深度和叶片由验证选。
2. 已知充放电协议局部树；不足6个训练电芯回退全家族模型，不看测试寿命。
3. 训练电芯未来标签拟合a-b*h-c*h²（h=(源循环-100)/100，b/c≥0），
   早期信号预测这些参数，输出连续曲线。参数拟合只用于训练电芯；
   新电芯参数只能由V/I特征给出。该简化模型是文献启发的消融，不称完整复现。
4. 若上述不能解释加速，增加平滑分段/拐点参数或趋势＋残差小网络；新增
   搜索须在训练侧记录新阶段配置，不能据外层失败为指定电芯手工校正。

NASA首轮在上述11候选之外保留当前Ridge的3个既定alpha候选
（0.1/10/100），共14候选，仅按新验证评分比较；确定性重复不当独立实验。
该预算在本Goal首次NASA训练开始前记录，不由外层结果决定。
