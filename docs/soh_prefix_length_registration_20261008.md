# 前期输入长度对照实验

目的：寻找同类型未见电池未来SOH曲线预测所需的最短前期电信号历史。
输入长度：10、20、30、50、75、100个绝对源循环；不是训练电芯数量。
第一轮使用四个队列固定第1折的训练/内层验证电芯，5个种子。
通过后扩展全部固定折；第一轮不能用于宣称全队列最短输入长度。

公平比较：所有输入长度使用相同的第101循环起真实未来标签和相同电芯交集。
因此比较的是历史信息量，不能等同于各起点的全部未来预测误差。
另外逐起点报告可用电芯数、缺失原因和实际输入记录数，不以删难电池提分。
容量/SOH仅用于训练监督和评价；预测特征为允许的早期电信号和已知工况。
寿命比例20%/40%只能用于回顾性分析，实际寿命不能作为部署时输入。

候选固定：Ridge(alpha=10)、ExtraTrees(80棵, leaf=1)、ExtraTrees(80棵, leaf=4)。
每颗电芯最多均匀抽96个训练目标、等电芯权重；保持相同候选预算。
这是输入长度筛查基线，不冒充已优化主模型的输入长度结论。
每个候选分别保存模型、配置、日志、预测数组和逐芯指标。
训练统计量仅训练电芯拟合，外层电芯不读取。

报告MAPE、MAE、末20%MAPE、起终点/总下降误差及三阶段下降误差。
阶段边界为有效未来绝对循环范围的0、1/3、2/3、1位置；
每个边界取最近最多5个观测的中位数，三阶段实际下降量差最大值作为阶段误差。
形状诊断以最后段下降减第一段下降为加速量，真实超过1pp且预测<-1pp为方向反转。
宽松筛查：MAPE<=6%；曲线筛查还要求MAE<=1pp、末20%MAPE<=2%、
终点及总下降误差<=2pp、阶段下降误差<=2pp、无明显加速方向反转。
归一化MAE=MAE_pp/max(abs真下降pp,2pp)<=25%。
这不是完整v3最终验收（可信拐点检测及完整覆盖审计尚待完成）。
短覆盖（<10观测或跨度<100循环）单列，不宣称完整曲线成功。
最短长度需在多折5种子结果中通过标准，且更长长度没有显著/实质优于它；
最终还需要改进后的主模型重新确认，不能用一折或一种基线下结论。
