# 同类型新电芯 SOH 预测与 STM32 部署 Goal

> 2026-10-04用户最新修订：当前执行与验收以`docs/soh_public_validation_current_goal.md`为准。下文STM32上板和用户额外新数据验收转为后续方向，不再阻塞本阶段NASA改进与公开数据训练。旧部署交付保留；本阶段不因未提供板卡而暂停算法工程。

日期：2026-10-04。依据用户本轮明确的工程目标，收敛执行范围；已有数据、划分、模型、预测和失败记录继续保留。

## Goal

训练并导出一个适合 STM32 的轻量 SOH 预测器：按真实电池类型与已知工况组织 MIT、XJTU、NASA 数据，对训练中未见过、但物理类型已被覆盖的新电芯，仅使用前 N 个源循环的电压、电流、可用温度及已知规格/工况，预测其后的 SOH 曲线。在整电芯独立验证中，各数据集分别争取电芯等权 MAPE ≤6%；同时给出逐电芯误差、后期误差及完整真实/预测曲线，并验证 C 实现和部署资源。

当前只处理未来 SOH 预测。实时 SOH 估计、独立 RUL、大语言模型消融、跨化学体系泛化及新数据集扩展，不作为这个工程 Goal 的前置条件。旧研究实验不自动停止或删除，独立保存，亦不作为新项目的完成依据。

## 任务边界与使用方式

- 已知规格选择物理类型：厂家/型号、化学体系、额定容量、电压范围。MIT 与 NASA 不因曲线相似而归入同类型；XJTU 不因同为18650而归入MIT。
- 每个物理家族独立模型，或共享小编码器加独立输出头；第一版优先独立模型。倍率、温度、充电策略作为工况输入或训练内分组。不要把批次来源直接当化学类型。
- 第一版给定类型，由规则/注册表选择模型，不额外训练复杂电池类型分类器。未知型号或工况超出训练覆盖时输出不支持/覆盖不足。
- N先固定为100个源循环，20/50作为补充能力；不是只有一次瞬时V/I读数就承诺可靠预测完整寿命。可以逐循环更新特征，再重新预测。
- 预测输入为早期信号和用户请求的未来循环数。输入禁止包含待预测电芯的容量/SOH、未来V/I、真实总寿命、真实EOL，或按真实寿命划分的“400/800循环类型”。训练电芯完整未来曲线可作为监督标签。
- 单片机周期性更新早期特征，再逐点计算 SOH(n)。整条曲线可由上位机请求多个未来循环得到，单片机无需保存1000点结果。
- 默认未来工况与已知策略保持一致；实际策略改变需更新工况输入，并检查训练覆盖。

## 数据与整芯验证

1. 复用现有数据与真实物理注册，先统一单位、初始容量参考规则及每芯角色。
2. 仅以预先固定的数据完整性规则排除错误数据：重复/倒序时间、单位错误、非有限值、物理不可能值、记录损坏、协议中断/明显非可比容量测试等。短记录按最低观测长度和预测目标长度判定适用性。正常容量恢复、短寿命或预测误差大不能自动作为异常。
3. 保存排除前后的电芯/循环数量、理由及名单。预测失败和误差高的正常电芯仍进入结果，不能只保留容易的电芯。
4. 同一颗电芯全部循环保持同一角色。主验证用数据集内按电芯分组的5折，约80%开发/20%测试；每折开发电芯内再留验证电芯选特征、模型大小和超参。所有归一化、特征选择和量化校准仅使用训练部分。
5. 内层选定方案后允许用开发电芯重训，外层测试电芯始终隔离。重复至少5个种子；已有冻结外折可复用，避免为好看结果反复重划分。
6. MIT、XJTU分别优先证明工程路线。NASA只有4颗，使用LOBO独立补充，保持6%的努力目标并报告数据不足；不能把NASA失败通过混入MIT均值隐藏，也不能保证4颗数据能够验证同样的落地能力。
7. 已经多次查看的公开数据属于开发验证；用户后续提供的新电芯作为最终独立评测。

## 精度与曲线指标

- 主任务：前100源循环预测其后全部有效观测SOH。每颗电芯先算MAPE，再等权汇总；各数据集分别目标≤6%。SOH全工程为容量/初始可比容量，数值0–1。
- 补充：固定+50/+100/+200循环窗口，报告覆盖电芯和不能评测的原因；比较不同N时另用相同电芯、相同未来区间，避免窗口变短带来假改善。
- 必报MAE、RMSE、MAPE、R²；逐电芯和种子均值±SD均保存。MAE/RMSE显示可换算为SOH百分点，MAPE为相对百分误差。
- 报后半程MAPE、最后100个已观测循环误差及末点误差。曲线在拐点附近仍可能失配，即使全程MAPE≤6%；要明确标注，不能用平均数掩盖。
- 保留现有全尺寸ExtraTrees作精度参照。在同划分上比较轻量模型，不把小规模诊断1.48%直接当全队列性能。

## 模型路线：仅三个主要候选

**优先：小型ExtraTrees。** 限制树数、深度、总节点和输入特征；从8/16/32棵、深度4/5/6的小网格开始，先使用16棵深度5。特征选择在训练/内层验证完成。导出常量节点表与简单C遍历函数，权重置于Flash。输出SOH(n)，形状由训练数据学习，不对测试真值事后拟合。

**第二候选：小型MLP。** 选择约16–32个最终统计输入，加未来循环/工况，以32→16→1隐藏结构为初始候选，参数量在几千级。先直接用训练真值监督；若有必要，再利用训练电芯上交叉拟合的树输出做蒸馏，仍保留真实标签。蒸馏不保证优于直接训练，不使用外层测试信息。模型输出连续数值，INT8量化校准仅训练数据，必要时量化感知训练。

**第三候选：小型分段退化模型。** 用早期统计特征预测少量衰减/拐点参数，并进行训练内正则化，作为低资源备选。此前固定单调曲线头效果较差的结果保留；该候选若验证不改善就不推进。

优先选择同时满足精度与资源预算、实现最简单的方案；不用预训练LLM作为单片机运行主体。新增复杂序列架构仅在这三类都未满足目标、且诊断证明需要时考虑。

## STM32资源与数据流

具体STM32型号未指定。先设可调整的工程预算，而非宣称已在硬件上达成：

- 单个已选物理家族的预测模块：Flash≤64KiB，运行RAM≤16KiB。
- Flash计入导出权重、归一化常量、特征处理和推理代码；RAM计入历史环形缓冲、工作区、栈等。完整系统还需给ADC/通信/应用留空间。
- 如一个固件同时驻留多类模型，必须报告所有模型合计Flash，不能把单模型预算冒充整机预算。允许按产品电池型号编译相应模型。
- 先在PC编译C验证，再针对实际STM32交叉编译；最终用链接map和板上测量核验Flash、峰值RAM和延迟。
- 单个未来循环点推理暂以≤20ms为设计目标；须标注芯片、时钟及编译设置。没有指定板卡或实际运行时，只交付资源估算和C重放，不宣称完成上板部署。
- 原始电压/电流采样在线提取平台统计、固定时刻电压、电压变化、电流均值等；只保留必要初始特征和最近短窗口，不保存全部原始波形或全部寿命历史。
- PC与MCU共用特征定义、单位、采样窗口、缺失值规则和归一化常量。先复现现有统计特征，再缩减为可在线计算的特征，避免PC好看、板上输入不一致。
- 纯树模型用自有简单C导出，先核验模型数值；小型NN可采用STM32Cube.AI/INT8路线。不得未经验证就承诺工具支持某个具体ExtraTrees算子/转换链。

现有恢复树模型的一份检查记录：160棵、103176节点、最大深度22，joblib文件7540015字节。此Python文件大小不是C程序Flash测量；节点数说明仍需限深/压缩，不能原样认作MCU小模型。

## 执行顺序与阶段门槛

1. **冻结小工程合同。** 数据质量、类型、整芯划分、SOH定义、输入N和资源预算落盘；复用可靠基线。对MIT先做一个折、一个种子的冒烟，核验标签不进输入。
2. **小模型精度筛选。** 在内层验证筛选三类候选，先MIT、再XJTU，NASA独立处理；比较特征缩减和模型大小影响。选定方案后跑整芯外折、五种子，逐芯保存所有结果。
3. **导出与量化。** 导出C/头文件和常量，PC编译重放相同输入。浮点版以绝对SOH差≤1e-5作初始数值一致性门槛；INT8版本要求同一验证集MAPE劣化≤0.5个百分点，且部署版仍争取≤6%。不同算子浮点误差若超出应解释和定位，不能静默放宽。
4. **板级验证。** 选择实际STM32型号后，完成交叉编译、链接资源核验、板上推理与特征提取重放。采集一段真实测试数据验证端到端特征一致性；公共数据测试并不替代真实传感链验证。
5. **独立验收。** 用用户后来提供的未训练电芯，按规格分配对应模型并评估。未知类型拒绝或标注需要新增训练。

## 交付与完成判定

- `type_registry.json`、质量排除清单、整芯划分、训练配置与特征合同。
- 每次训练的权重、配置、种子、日志、预测、逐芯四指标和曲线；所有失败保留。
- `summary.csv`与各数据集独立结果表；完整正常电芯覆盖和≤6%的比例。
- MCU所需模型C/头文件、在线特征提取C、PC重放工具及对照样例。
- 各类型模型及合计资源表、量化精度影响、实际板上延迟/峰值RAM/Flash报告。
- 数据集达到或未达到目标都如实标明。MIT/XJTU成功不自动表示NASA成功；离线达标不自动表示部署达标。无具体硬件时板级阶段保持待验收。
